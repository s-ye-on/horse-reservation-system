# ADR 001: 쿠폰 임시 점유와 승인대기 경고

## 상태

확정

## 맥락

쿠폰 예약은 관리자 승인 전에도 정원을 점유한다. 실제 차감을 승인 또는 수업 완료까지 미루면 잔여 1회인 쿠폰으로 여러 예약을 신청할 수 있다. 또한 쿠폰 예약의 승인대기를 자동 만료하지 않으면 오래된 신청이 운영 화면에서 묻힐 수 있다.

## 검토한 대안

1. 관리자 승인 시점에만 쿠폰을 점유한다. 구현은 단순하지만 승인대기 예약이 쿠폰 잔여 횟수를 초과할 수 있다.
2. 예약 신청 시 쿠폰을 즉시 차감한다. 중복 사용은 막지만 아직 승인되지 않은 예약이 실제 사용처럼 보이고 반환 처리가 많아진다.
3. 예약 신청 시 임시 점유하고 수업 완료 시 차감한다. 상태가 늘어나지만 실제 사용과 예약 약속을 구분할 수 있다.

승인대기 경고는 고정 경과 시간만 보는 방식과 수업 임박 여부만 보는 방식도 검토했다. 하나만 사용하면 오래된 미래 예약 또는 임박한 신규 예약을 놓칠 수 있다.

## 결정

- 예약 신청 시 쿠폰 1회를 임시 점유한다.
- 관리자 승인 시 확정 점유로 바꾸고 수업 완료 시 실제 차감한다.
- 반려 시 `rejected`, 취소 시 `cancelled`로 구분하고 반환 대상이면 점유를 해제한다.
- 승인대기는 자동 만료하지 않는다.
- 신청 후 2시간이 지나면 확인 필요, 신청 후 24시간이 지나거나 수업 시작까지 24시간 이하면 긴급으로 표시한다.
- 경고 시간은 운영 설정으로 변경 가능하게 한다.

## 결과

쿠폰 초과 예약을 방지하고 회원에게 예정 사용과 실제 사용을 구분해 보여줄 수 있다. 대신 예약·쿠폰 처리를 하나의 트랜잭션으로 묶고 임시 점유 해제 누락을 테스트해야 한다.

## 검증

- 잔여 1회 쿠폰으로 동시에 두 예약을 신청했을 때 하나만 성공해야 한다.
- 반려·취소 후 임시 점유가 다시 사용 가능하고 두 상태가 구분되어야 한다.
- 승인대기 경고가 상태와 정원 점유를 변경하지 않아야 한다.
- 경고 경계 시각을 `Asia/Seoul` 기준으로 테스트해야 한다.
