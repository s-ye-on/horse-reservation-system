`DONE`

`dev-workflow`

- M0-03 완료
- M0-05 완료

## 허용 범위

- `scripts/verify-changed.sh`
- `scripts/tests/verify-changed-test.sh`
- `mise.toml`
- `docs/tasks/active/M0-06.md`
- `docs/tasks/completed/M0-06.md`

## 제외 범위

- GitHub Actions 등 CI 공급자 설정
- 애플리케이션 기능과 테스트 변경
- 병렬 실행 및 원격 캐시
- 관련 없는 스크립트 리팩터링

## 완료 조건

- [x] 백엔드와 웹 변경이 각각 필요한 검증 task를 실행한다.
- [x] API 계약·공유 패키지·모바일·문서·공통 하네스 변경을 올바르게 분류한다.
- [x] working tree와 지정된 Git 기준 ref 비교를 모두 지원한다.
- [x] 라우팅 회귀 테스트와 모든 검증 명령이 성공한다.

## 검증 명령

```bash
mise tasks --all
mise run verify:m0-06
mise run verify:changed
```

## 검증 증거

| 명령 | 종료 코드 | 핵심 결과 |
|---|---:|---|
| `mise tasks --all` | 0 | `verify:m0-06` 존재 확인 |
| `mise run verify:m0-06` | 0 | 영역별·기준 ref 라우팅 테스트 통과 |
| `mise run verify:changed` | 0 | 공통 변경 감지 후 전체 품질 게이트 통과 |

## 중단 조건

- 변경 경로를 결정적으로 수집할 수 없다.
- 검증 task가 자기 자신을 재귀 호출한다.
- 필수 영역 변경이 검증 없이 성공 처리된다.
- CI 공급자 설정을 수정해야만 검증할 수 있다.
