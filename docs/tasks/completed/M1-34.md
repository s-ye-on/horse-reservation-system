## 검증 명령

```bash

mise run verify:m1-34
mise run verify:changed
```

## 검증 증거

| 명령 | 종료 코드 | 핵심 결과 |
|---|---:|---|
| `mise tasks --all` | 0 | M1-34 검증 task 등록 확인 |
| `mise run verify:m1-34` | 0 | 제품 및 ADR 문서 링크와 구조 검사 통과 |
| `mise run verify:changed` | 0 | 문서, 백엔드, API 계약, 웹, 모바일 전체 변경 검증 통과 |

## 완료 증거

- MVP-1 인증 범위를 JWT 검증과 역할 기반 API 권한 경계로 한정했다.
- 로그인과 토큰 수명주기 및 저장은 후속 MVP로 명시했다.
- 개발용 fallback을 배포 차단 설정으로 분류해 도메인 완료 기준과 분리했다.
- 운영 Secret과 API URL 환경변수 강제는 현재 미구현인 별도 배포 전 task임을 명시했다.

## 중단 조건

- 실제 로그인 구현 시점이 기존 MVP 문서와 충돌한다.
- 인증 정책 변경이 필요하다.
- 허용 범위 밖 문서 수정이 필수다.
