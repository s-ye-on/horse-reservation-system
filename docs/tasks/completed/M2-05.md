## 제외 범위

- 공휴일과 임시 휴무일을 주말로 취급하는 정책
- 주말의 다른 날짜 변경과 무료 변경권 정책 변경
- 예약 취소와 화면 구현
- 관련 없는 리팩터링, 라이브러리 교체, 포맷 전체 변경

## 완료 조건

- [x] 마감 후 토요일과 일요일 수업의 같은 날짜 내 시간 변경은 거부한다.
- [x] 무료 변경권이 남은 쿠폰 예약도 주말 당일 변경에는 무료 변경권을 소비하지 않고 거부한다.
- [x] 응답은 주말 당일 변경 불가를 구분할 수 있는 안정적인 예외 코드를 제공한다.
- [x] 거부 시 예약 일정, 정원, 쿠폰, 감사 이력이 변경되지 않는다.
- [x] 검증 명령이 모두 종료 코드 0으로 성공한다.

## 검증 명령

```bash
mise tasks --all
mise run verify:m2-05
mise run backend:convention
mise run verify:changed
```

| 명령 | 종료 코드 | 핵심 결과 |

## Completion Evidence

- `AFTER_CUTOFF_WEEKEND`이면서 대상 수업일이 같으면 전용 예외 코드로 거부한다.
- 무료 변경권 보유 쿠폰도 토요일·일요일 당일 변경에서 소비되지 않는다.
- 거부 후 예약 일정, Coupon 상태, CouponUsageLog, ReservationChangeLog가 유지됨을 API 테스트로 검증한다.
- 공휴일은 현재 정책대로 제외 범위에 남겼다.
- `backend/conventions/review.md`의 Architecture, DDD, Exception, Code Style, Package, Test 항목을 점검했다.

## 중단 조건

- 주말 당일 변경을 무료 변경권으로 허용해야 한다는 정책이 추가된다.
- 공휴일 달력 연동이 현재 task의 필수 조건이 된다.
- 기존 감사 이력을 수정·삭제해야 한다.
