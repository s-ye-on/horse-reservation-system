- 평일의 다른 날짜 변경을 무료 변경권 없이 허용하는 정책
- 예약 취소와 변경 화면
- 관련 없는 리팩터링, 라이브러리 교체, 포맷 전체 변경

## 완료 조건

- [x] 마감 후 평일 예약은 같은 수업일의 다른 시간대로 변경할 수 있다.
- [x] 쿠폰 예약과 1회 결제 예약 모두 허용하며 쿠폰 예약도 무료 변경권과 쿠폰 사용 이력을 변경하지 않는다.
- [x] 무료 변경권이 남은 쿠폰도 평일 당일 변경에서는 소비하지 않으며 응답·감사 이력의 couponAction은 `none`이다.
- [x] 평일이라도 무료 변경권 없는 다른 날짜 변경은 거부한다.

## Completion Evidence

- `AFTER_CUTOFF_WEEKDAY`이면서 원본과 대상 수업일이 같을 때 무료 변경권 경로보다 먼저 변경을 허용한다.
- 쿠폰 예약과 1회 결제 예약 모두 같은 Reservation을 변경하고 `couponAction=none`을 반환한다.
- 평일 당일 쿠폰 변경은 `free_change_used` 필드와 CouponUsageLog를 변경하지 않는다.
- 무료 변경권이 없는 다른 날짜 변경은 기존 마감 후 정책에 따라 거부한다.
- `backend/conventions/review.md`의 Architecture, DDD, Exception, Code Style, Package, Test 항목을 점검했다.

## 중단 조건

- 평일 당일 변경에도 무료 변경권을 우선 소비해야 한다는 정책이 추가된다.
- 평일 판단 기준이 수업일이 아닌 요청일로 변경된다.
- 기존 감사 이력을 수정·삭제해야 한다.
- 완료 조건을 자동 검증할 수 없다.
