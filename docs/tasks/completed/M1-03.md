## 중단 조건

- `TimeSlotCapacity.class_capacity_json`을 다른 저장 구조로 바꾸어야만 제약을 구현할 수 있다.
- 날짜·시각을 UTC instant로 저장해야 하는지 `Asia/Seoul` 로컬 값으로 저장해야 하는지 기존 convention과 입력 문서가 충돌한다.
- 기존 migration을 수정하거나 데이터 삭제·비가역 변환을 해야 한다.
- 검증 task를 만들기 위해 `mise.toml` 이외의 하네스 구조 또는 convention 변경이 필요하다.
- DB가 지원하지 않는 제약을 애플리케이션 코드로 옮겨야 하여 스키마 작업 범위를 넘는다.
