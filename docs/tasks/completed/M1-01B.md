## 중단 조건

- 확정 규칙을 적용하려면 기존 DB migration 또는 API 계약 변경이 필요하다.
- 자동 검사에서 현재 기준선을 정당한 예외 없이 통과시킬 수 없다.
- ArchUnit·Checkstyle가 Java 21/Spring Boot 4 빌드와 호환되지 않는다.
- 작업 범위가 프론트엔드나 제품 기능 구현으로 확장된다.

## Completion Evidence

- `backend/conventions`의 12개 문서와 `backend/AGENTS.md` 라우팅으로 백엔드 규칙의 입력 경계를 고정했다.
- `BusinessException`, 단일 `ExceptionCode`, `MemberException`, `GlobalExceptionHandler`가 오류 처리 기준선을 제공한다.
- ArchUnit 9개 규칙, Checkstyle, 예외 코드·전역 처리·회원 도메인·MySQL Repository 테스트가 규칙을 자동 검증한다.
- `backend:convention`은 `verify:changed`와 CI의 `verify:all` 경로에 연결됐다.
