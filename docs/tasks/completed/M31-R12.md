## Completion Evidence

### 구현

- 정규 Template과 정기 휴일을 요일, 시작 시각 또는 적용 시작일, PK 순으로 안정적으로
  정렬하고 검색·요일·활성 상태 필터와 loading·empty·error 상태를 제공한다.
- 생성·변경·활성화는 서버 영향 미리보기 뒤 미리보기 시점의 config version으로만
  확정한다. 미리보기와 Command 중복 제출을 각각 차단한다.
- SYNCING 진행률, 시작 시각, 장기 실행 경고와 최근 완료·실패 시각, 실패 코드·요약을
  `Asia/Seoul` 기준으로 표시한다. SYNCING 전환 후 열린 dialog도 확정을 차단한다.
- 45분·자정·정원 관계·요일·기간을 client에서 보조 검증하되 서버 계약에 없는 정원
  상한은 정의하지 않는다.
- API adapter는 생성된 Template·정기 휴일·동기화 Client만 사용하며 직접 `fetch`나
  중복 request/response DTO를 추가하지 않았다.
- dialog focus trap, Escape 닫기, trigger focus 복귀, 오류 설명 연결과 320px 무가로
  overflow를 검증했다.

### 검증과 보정

- 데모 프록시가 OpenAPI 생성 서버와 동일한 8080 포트를 점유해 첫
  `verify:changed`가 실패했다. 데모를 내리고 게이트를 재실행해 OpenAPI와 생성 Client
  drift가 없음을 확인했다.
- 웹 전체 테스트에서 dialog heading focus가 effect 타이밍에 따라 한 번 실패했다.
  dialog 배치 시점에 focus를 확정하도록 `useLayoutEffect`로 보정했고 전체 142개 웹
  테스트에서 재현되지 않았다.
- 전용 검증은 R12 화면과 route 테스트 16건, lint, TypeScript와 production build를
  실행한다.
