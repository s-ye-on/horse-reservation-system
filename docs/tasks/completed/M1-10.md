## 중단 조건

- `coupon_id` 외 별도 `planned_coupon_id`를 다시 도입해야 한다는 기존 계약이 발견된다.
- `rejected`와 `cancelled`를 하나의 상태로 저장하거나 기존 상태값을 변경해야 한다.
- 날짜·시각 기반 시간대 연결을 `timeslot_id` 외래 키로 바꾸어야만 무결성을 보장할 수 있어 도메인 모델 변경이 필요하다.
- 상태별 감사 필드와 결제 출처 nullable 조합이 입력 문서끼리 충돌한다.
- 기존 예약 데이터의 삭제·재작성 또는 다른 migration 수정이 필요하다.
