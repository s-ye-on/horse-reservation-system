## 완료 조건

- [x] 회원 조회는 당일 수업 중 현재 시각과 같거나 이전인 TimeSlot을 노출하지 않는다.
- [x] 회원 예약 신청은 당일 수업 시작 직전까지 성공한다.
- [x] 정확한 시작 시각부터 직접 API 신청을 `RESERVATION_LESSON_ALREADY_STARTED`로 거부한다.
- [x] 모든 검증 명령이 종료 코드 0으로 성공한다.

## Completion Evidence

- 회원 시간대 조회는 한 번 캡처한 서버 `Instant`로 시작된 당일 슬롯을 응답에서 제외한다.
- 조회 날짜의 과거 여부도 서버 `Clock`을 서울 날짜로 변환해 검증하므로 테스트와 운영 기준이 같다.
- 회원 예약 Command는 TimeSlot 비관적 잠금 이후 M31-01 Domain Policy로 시작 경계를 재검증한다.
- 수업 시작 직전 신청은 성공하고 정각 신청은 409와 `RESERVATION_LESSON_ALREADY_STARTED`를 반환한다.
- 기존 `reservable/unavailableReason` Read Model과 OpenAPI 구조를 유지하고 Scheduler 상태에 의존하지 않는다.
- `review.md` 기준 Controller, DTO, Entity와 Repository 경계를 변경하지 않고 Application 흐름만 조합했음을 확인했다.

## 중단 조건

- 조회와 Command가 서로 다른 시간 정책을 요구한다.
- 시작된 TimeSlot을 목록에 남겨야 하는 새 제품 요구사항이 발견된다.
- 완료하려면 API 스키마 또는 DB migration 변경이 필요하다.
- 같은 원인의 검증 실패가 세 번 반복된다.
