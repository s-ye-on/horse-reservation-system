## 중단 조건

- Spring Boot 4와 호환되는 Springdoc 버전을 사용할 수 없다.
- 생성기가 네트워크 최신 버전에 의존해 결과를 고정할 수 없다.
- 실제 도메인 endpoint 구현이 필요하다.
- 허용 범위 밖의 파일 수정이 필요하다.
- 필수 검증이 반복 실행 시 다른 결과를 만든다.
