## 완료 조건

- [x] `@ModelAttribute` Query DTO 사용 지점을 전수 점검하고 `@ParameterObject`를 적용한다.
- [x] OpenAPI가 `status`, `lessonDateFrom`, `lessonDateTo`, `classType`, `keyword`, `page`, `size`를 평면 query parameter로 제공한다.
- [x] 생성 TypeScript 클라이언트 RequestOpts가 `request[status]`가 아닌 `status` query key를 만든다.
- [x] OpenAPI와 TypeScript 클라이언트를 재생성하고 검증 명령이 모두 종료 코드 0으로 성공한다.

## 중단 조건

- `@ParameterObject`가 Spring Boot 4 또는 Springdoc 3과 호환되지 않는다.
- 평면 parameter 생성에 Controller 서명이나 제품 API 변경이 필요하다.
- 다른 `@ModelAttribute` Query DTO에서 서로 다른 계약 결정이 필요하다.
- 생성기 설정 또는 기존 API 검증 규칙을 완화해야 한다.
