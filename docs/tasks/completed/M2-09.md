# M2-09: 회원 예약 취소 화면

## 상태

`COMPLETED`

## 목표

회원이 활성 예약의 취소 예상 결과를 확인하고 필수 사유를 입력해 예약을 취소한다.

## 담당

`frontend`

## 선행 작업

- M2-06 완료

## 입력 문서

- [MVP 2 Backlog](../mvp-2.md)의 `M2-09`
- [운영 정책](../../product/policies.md)의 `예약 취소`
- [API 초안](../../architecture/api.md)의 회원 취소 API

## 허용 범위

- `frontend/apps/web/src/app.tsx`
- `frontend/apps/web/src/features/my-reservations/**`
- `frontend/apps/web/src/features/reservation-cancel/**`
- `docs/tasks/active/M2-09.md`, `docs/tasks/completed/M2-09.md`
- `mise.toml`의 `verify:m2-09` 등록

## 제외 범위

- 관리자 취소와 쿠폰 처리 재정의
- 결제 환불 자동화
- 취소 정책 또는 API 계약 변경
- 모바일 앱 화면
- 관련 없는 리팩터링과 디자인 시스템 교체

## 완료 조건

- [x] 활성 예약 카드에서만 취소 화면으로 이동할 수 있다.
- [x] 서버 preview의 마감 기준과 예상 쿠폰 처리를 실행 전에 표시한다.
- [x] 500자 이하 필수 사유를 입력해야 취소할 수 있다.
- [x] 취소 성공 후 상태, 취소 시각, 최종 쿠폰 처리를 표시하고 예약 목록을 갱신한다.
- [x] 로딩·비활성 예약·정책 거부·API 오류·모바일 폭 상태를 테스트한다.
- [x] 검증 명령이 모두 종료 코드 0으로 성공한다.

## 검증 명령

```bash
mise tasks --all
mise run verify:m2-09
mise run backend:convention
mise run verify:changed
```

## 검증 증거

| 명령 | 종료 코드 | 핵심 결과 |
|---|---:|---|
| `mise tasks --all` | 0 | M2-09 검증 task 등록 확인 |
| `mise run verify:m2-09` | 0 | 웹 lint, typecheck 및 회원 취소 화면 테스트 통과 |
| `mise run backend:convention` | 0 | Checkstyle 및 아키텍처 규칙 테스트 통과 |
| `mise run verify:changed` | 0 | backend, OpenAPI, web, mobile 및 문서 변경 검증 통과 |

## Completion Evidence

- 활성 예약 카드에만 취소 진입점을 표시한다.
- 회원 취소 preview의 마감 기준과 예상 쿠폰 처리를 표시하며 회원이 결과를 재정의하지 못하게 한다.
- 500자 이하 필수 사유를 검증하고 성공 후 취소 상태, 시각, 최종 쿠폰 처리를 표시한다.
- 로딩, 비활성 예약, 정책 충돌, API 오류와 320px 폭 테스트를 추가했다.

## 중단 조건

- 회원 화면에서 쿠폰 처리 결과를 재정의해야 한다.
- preview와 실행 API의 정책 판정이 서로 다르다.
- 기존 취소 API 계약을 호환되지 않게 수정해야 한다.
- 완료 조건을 자동 검증할 수 없다.
