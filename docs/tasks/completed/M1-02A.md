# M1-02A: 관리자 회원 조회 API

## 상태

`DONE`

## 목표

관리자가 회원 목록과 회원 상세의 기승 횟수·승인 상태를 조회한다.

## 담당

`backend`

## 선행 작업

- M1-02 완료

## 입력 문서

- `docs/architecture/api.md`의 회원과 쿠폰
- `docs/architecture/domain-model.md`의 `Member`
- `backend/conventions/README.md`

## 허용 범위

- `backend/src/main/java/com/horse/members/application/**`
- `backend/src/main/java/com/horse/members/presentation/**`
- `backend/src/main/java/com/horse/members/infrastructure/**`
- `backend/src/test/java/com/horse/members/**`
- `backend/openapi/horse-api.json`
- `frontend/packages/api-client/src/**` (API 생성 결과만)
- `docs/tasks/active/M1-02A.md`
- `docs/tasks/completed/M1-02A.md`

## 제외 범위

- 회원 가입·삭제·개인정보 수정
- 특수 클래스 승인 변경
- 쿠폰과 예약 조회
- 페이지네이션 정책 추가와 관련 없는 리팩터링

## 완료 조건

- [x] ADMIN만 회원 목록과 상세를 조회할 수 있다.
- [x] 응답에 일반·특수 기승 횟수, 특수 승인, 파생 대마장 가능 여부가 포함된다.
- [x] 존재하지 않는 회원과 MEMBER 접근 오류가 자동 검증된다.
- [x] 검증 명령이 모두 종료 코드 0으로 성공한다.

## 검증 명령

```bash
mise tasks --all
mise run verify:m1-02a
mise run verify:changed
```

## 검증 증거

| 명령 | 종료 코드 | 핵심 결과 |
|---|---:|---|
| `mise tasks --all` | 0 | `verify:m1-02a` 등록 확인 |
| `mise run verify:m1-02a` | 0 | ADMIN 목록·상세, MEMBER 거부, 회원 없음 API 테스트 4건 성공 |
| `mise run verify:changed` | 0 | backend convention·check·integration·OpenAPI·문서 검증 성공 |

## 중단 조건

- 회원 목록에 검색·정렬·페이지네이션이 필수라는 새로운 운영 요구가 발견된다.
- 관리자 응답에 현재 문서에 없는 개인정보가 필요하다.
- 인증 경계 또는 회원 스키마 변경이 필요하다.

## Completion Evidence

- `GET /api/admin/members`가 회원을 ID 오름차순으로 조회한다.
- `GET /api/admin/members/{memberId}`가 일반·특수 기승 횟수, 특수 승인과 파생 대마장 이용 가능 여부를 응답한다.
- `/api/admin/**` JWT 권한 경계로 MEMBER 요청을 거부하고, 존재하지 않는 회원은 `MEMBER_NOT_FOUND`로 응답한다.
