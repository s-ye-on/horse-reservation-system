# M1-01: 클래스 enum과 일반 등급 판정

## 상태

`DONE`

## 목표

예약 클래스 종류와 일반 기승 완료 횟수에 따른 회원 등급 판정을 순수 도메인 코드로 고정한다.

## 담당

`backend`

## 선행 작업

- M0-01 완료

## 입력 문서

- [MVP 1 Backlog](../mvp-1.md)의 `M1-01`
- [제품 요구사항](../../product/requirements.md)의 클래스와 등급
- [도메인 모델](../../architecture/domain-model.md)의 회원 일반 기승 횟수
- [시스템 개요](../../architecture/system-overview.md)의 `members` 경계

## 허용 범위

- `backend/src/main/java/com/horse/members/domain/**`
- `backend/src/test/java/com/horse/members/domain/**`
- `mise.toml`
- `docs/tasks/active/M1-01.md`
- `docs/tasks/completed/M1-01.md`

## 제외 범위

- DB와 Flyway migration
- API와 DTO
- 회원 조회 및 특수 클래스 승인
- 예약 가능 클래스 계산
- 관련 없는 리팩터링과 의존성 변경

## 완료 조건

- [x] 일반 클래스 5개와 마장마술·장애물 클래스가 enum으로 정의된다.
- [x] 0·1·5·6·20·21·25·26회 경계가 확정 정책대로 판정된다.
- [x] 음수 일반 기승 횟수는 거부된다.
- [x] 검증 명령이 모두 종료 코드 0으로 성공한다.

## 검증 명령

```bash
mise tasks --all
mise run verify:m1-01
mise run verify:changed
```

## 검증 증거

| 명령 | 종료 코드 | 핵심 결과 |
|---|---:|---|
| `mise tasks --all` | 0 | `verify:m1-01` 존재 확인 |
| `mise run verify:m1-01` | 0 | 클래스 구분과 등급 경계 테스트 11건 통과 |
| `mise run verify:changed` | 0 | 전체 품질 게이트 통과 |

## 중단 조건

- 등급 경계가 입력 문서끼리 충돌한다.
- DB, API 또는 특수 승인 구현이 필요하다.
- 허용 범위 밖 파일 수정이 필요하다.
- 경계값을 자동 테스트로 검증할 수 없다.
