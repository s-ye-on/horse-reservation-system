# M3-13: 예약 Command 수업 시작 시각 가드

## 상태

`COMPLETED`

## 목표

승인·변경·취소는 수업 시작 전만, 완료·노쇼는 수업 시작 시각부터만 허용하도록 모든
단건·일괄 Command를 트랜잭션 실행 시점에 검증한다.

## 담당

`backend`, `qa`

## 선행 작업

- M3-12 완료

## 입력 문서

- [운영 정책](../../product/policies.md)
- [ADR-013](../../architecture/adr-013-time-based-reservation-lifecycle.md)

## 허용 범위

- `backend/src/main/java/com/horse/reservations/**`
- 관련 `backend/src/test/java/com/horse/reservations/**`
- `backend/src/main/java/com/horse/global/exception/ExceptionCode.java`
- `docs/tasks/active/M3-13.md`, `docs/tasks/completed/M3-13.md`

## 제외 범위

- 새 예약 상태와 Flyway migration
- Scheduler와 승인대기 정리 Job
- 조회 API와 프론트 화면
- 관련 없는 리팩터링, 라이브러리 교체, 포맷 전체 변경

## 완료 조건

- [x] 승인·변경·취소는 정확히 수업 시작 시각부터 서버에서 거부된다.
- [x] 완료·노쇼는 수업 시작 전 서버에서 거부되고 시작 시각부터 허용된다.
- [x] preview와 execute, 단건과 일괄 경로가 동일한 시간 규칙을 사용한다.
- [x] 검증 명령이 모두 종료 코드 0으로 성공한다.

## 검증 명령

```bash
mise tasks --all
mise run verify:m3-13
mise run backend:convention
mise run verify:changed
```

## 검증 증거

| 명령 | 종료 코드 | 핵심 결과 |
|---|---:|---|
| `mise tasks --all` | 0 | `verify:m3-13` 등록 확인 |
| `mise run verify:m3-13` | 0 | 도메인 시간 경계와 승인·변경·취소·완료·노쇼 API 테스트 통과 |
| `mise run backend:convention` | 0 | Checkstyle과 ConventionTest 통과 |
| `mise run verify:changed` | 0 | backend, MySQL, OpenAPI, web 127건과 build 검증 통과 |

## Completion Evidence

- 예약 Aggregate가 승인·변경·취소·복구와 완료·노쇼의 수업 시작 경계를 검증한다.
- Application Service가 `Clock`으로 한 번 계산한 현재 시각을 Aggregate와 쿠폰 처리에 전달한다.
- 회원·관리자 preview와 execute가 같은 도메인 검증을 사용한다.
- 정확한 수업 시작 시각과 시작 1나노초 전 경계를 도메인 및 API 테스트로 고정했다.

## 중단 조건

- 수업 종료 시각이 없으면 시작 경계를 구현할 수 없다.
- 기존 변경·취소 마감 정책과 시작 시각 가드가 충돌한다.
- 같은 원인의 검증 실패가 세 번 반복된다.
