- [x] `pending_admin_approval`, `pending_payment`, `payment_expired` 예약과 `normal`, `warning`, `critical` 경고가 서버 조회 결과대로 구분·정렬된다.

## 중단 조건

- M1-16A 조회 응답이 예약 상태, 결제 방식, 신청·수업 시각과 `normal`, `warning`, `critical` 경고를 제공하지 않는다.
- M1-16B 조회 응답이 `pending_payment`, `payment_expired`, `payment_due_at`, 현재 마감 여부를 제공하지 않는다.
- M1-13~M1-16 API의 허용 이전 상태나 상태 충돌·정원 부족 오류를 UI에서 구분할 수 없다.
- 요구사항 충족에 클라이언트 경고 시각 계산, 만료 job 호출, 생성형 API 클라이언트 직접 수정이 필요하다.
