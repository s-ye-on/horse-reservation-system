## Completion Evidence

### API와 필터

- 기존 ADMIN 전용 `GET /api/admin/audit-logs/export`를 생성 Client의
  `export1Raw()`로 호출한다.
- 목록과 export는 `keyword`, `reservationId`, `occurredDateFrom`,
  `occurredDateTo`, `actorType`, `changeType` 변환을 공유한다.
- export 입력 타입에서 `page`, `size`를 제외하여 HTTP 요청에 포함되지 않도록 했다.
- `text/csv` 성공 응답만 Blob으로 처리하며 JSON이나 다른 성공 응답은 다운로드하지 않는다.

### 파일명과 자원 정리

- `filename*`의 UTF-8 percent encoding과 선택적인 RFC 5987 language tag,
  quoted/plain `filename`을 순서대로 처리한다.
- 경로·제어 문자·Windows 예약명·trailing dot을 제거하고 헤더가 없거나
  유효하지 않으면 `reservation-audit.csv`를 사용한다.
- 성공 다운로드는 다음 browser task에서 object URL을 해제하고, click 전에 실패하면
  즉시 해제한다. 임시 anchor는 모든 경로에서 제거한다.

### UX와 오류

- 다운로드 중 ref guard와 `disabled` 버튼으로 중복 제출을 차단한다.
- 401, 403, 400, 500과 네트워크 오류를 기존 화면 패턴으로 안내하고 재시도할 수 있다.
- 다운로드 오류는 목록·Page·필터 상태를 초기화하거나 가리지 않는다.
- 필터 적용·초기화 시 이전 다운로드 오류를 제거한다.
- 실제 320px 브라우저에서 viewport와 문서 폭이 모두 320px이고, 다운로드 버튼은
  `left=26`, `right=294`, 필터 우측 경계는 `294`로 수평 잘림이 없었다.

### 서버 보안 계약

- `/api/admin/**`는 `ADMIN` authority로 제한되며 API 테스트에서 미인증 401,
  회원 403을 확인한다.
- `CsvEncoder`가 `=`, `+`, `-`, `@`와 leading whitespace 수식 값을
  apostrophe로 보호하고 모든 필드를 quote하는 것을 관련 테스트로 확인했다.
- 전화번호와 내부 인증 주체가 export되지 않는 기존 회귀 테스트가 유지된다.

### 독립 검토

- Frontend 1차 검토의 MEDIUM 2건(object URL 즉시 해제, RFC 5987 language tag)과
  LOW 2건(예약 파일명, 오래된 오류 상태)을 모두 보정했다.
- Frontend 재검토와 QA 검토 모두 남은 HIGH/MEDIUM finding이 없다.
- QA LOW: JSDOM 테스트는 실제 320px 미디어쿼리와 키보드 E2E를 자동 증명하지 않는다.
  실제 브라우저 반응형 검증을 보완 증거로 남겼다.

## 남은 위험

- CSV export는 현재 서버 byte array와 브라우저 Blob에 전체 결과를 적재한다. 감사
  데이터가 크게 증가하면 streaming export 또는 비동기 export를 별도 검토해야 한다.
- 320px과 실제 다운로드는 M31-14 전용 자동 브라우저 E2E Gate에 포함되지 않았다.
- 의존성 검토에서 기존 `react-router@8.2.0`의 `GHSA-qwww-vcr4-c8h2`가 확인됐다.
  M31-14 변경과 무관하며 별도 보안 Backlog에서 버전과 영향 범위를 다룬다.
- 로컬 의존성 audit는 레지스트리 응답 없이 장시간 대기해 현재 실행에서는 완료하지 못했다.
