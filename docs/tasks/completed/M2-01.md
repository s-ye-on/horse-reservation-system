# M2-01: 전날 21시 마감 판정기

## 상태

`COMPLETED`

## 목표

예약 변경·취소의 기준 시각과 평일·주말을 `Asia/Seoul` 기준으로 일관되게 판정한다.

## 담당

`backend`

- MVP 1 완료

- [MVP 2 Backlog](../mvp-2.md)의 `M2-01`
- [운영 정책](../../product/policies.md)의 `예약 변경`, `예약 취소`
- [시스템 개요](../../architecture/system-overview.md)의 정책 판정 권한과 시간 기준
- `backend/conventions/README.md`의 도메인·예외·테스트 규칙

## 제외 범위

- 예약 시간대·상태·정원 변경
- 쿠폰 차감·반환·무료 변경권 사용
- 변경·취소 API와 웹 화면
- 공휴일 또는 마장 자체 휴무일 판정
- 관련 없는 리팩터링, 라이브러리 교체, 포맷 전체 변경

## 완료 조건

- [x] 수업 전날 21:00 이전과 해당 시각 이후를 `Asia/Seoul` 기준으로 구분한다.
- [x] 마감 후 수업일이 월요일부터 금요일이면 평일, 토요일 또는 일요일이면 주말로 구분한다.
- [x] null 입력을 프로젝트 예외 체계로 거부하고 경계 테스트가 성공한다.
- [x] 검증 명령이 모두 종료 코드 0으로 성공한다.

## 검증 명령

```bash
mise tasks --all
mise run verify:m2-01
mise run backend:convention
mise run verify:changed
```

## 검증 증거

| 명령 | 종료 코드 | 핵심 결과 |
|---|---:|---|
| `mise tasks --all` | 0 | `verify:m2-01`, `backend:convention`, `verify:changed` 등록 확인 |
| `mise run verify:m2-01` | 0 | 서울 시각·21:00 경계·평일·주말·필수 입력 테스트 5건 성공 |
| `mise run backend:convention` | 0 | Checkstyle과 백엔드 convention test 성공 |
| `mise run verify:changed` | 0 | 문서, 백엔드, OpenAPI, 웹, 모바일 전체 품질 게이트 성공 |

## Completion Evidence

- `ReservationChangeDeadlinePolicy`가 요청 Instant를 `Asia/Seoul`로 변환해 수업 전날 21:00 경계를 판정한다.
- 정확히 21:00부터 마감 후로 처리하고 수업일 기준 토·일만 주말로 분류한다.
- 정책 판정은 예약·정원·쿠폰 상태를 변경하지 않는 순수 도메인 로직이며 잘못된 입력은 `RESERVATION_*` 예외 코드로 거부한다.
- `backend/conventions/review.md`의 Architecture, Domain, Exception, Code And Test 항목을 점검했다.

## 중단 조건

- 마감 시각 또는 기준 시간대를 입력 문서와 다르게 해석해야 한다.
- 공휴일을 주말과 동일하게 판정해야 한다는 요구가 추가된다.
- 판정 과정에서 예약·쿠폰·정원 상태를 변경해야 한다.
- 완료 조건을 자동 검증할 수 없다.
