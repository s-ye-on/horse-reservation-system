## Completion Evidence

- 활성 예약 상태는 `pending_admin_approval`, `pending_payment`, `confirmed`로 DB marker와 Domain enum에 일치한다.
- `mise run db:preflight-active-reservations`는 중복 그룹의 회원·수업 날짜·시각·예약 ID를 출력하고 실패한다.
- V15는 활성 상태에만 값이 있는 generated marker와 4열 UNIQUE로 종료 이력을 보존하며 활성 중복을 차단한다.
- 기존 활성 중복이 있는 V14 스키마는 V15 migration이 실패하고 임의 병합이나 삭제를 수행하지 않는다.
- 생성·변경 preview/실행·입금복구는 저장 전 `RESERVATION_DUPLICATE_ACTIVE_TIME_SLOT`을 반환한다.
- 같은 회원의 같은 슬롯 동시 신청은 하나만 201이며 예약과 쿠폰 점유도 한 번만 생성된다.
- `review.md` 기준 순수 불변식은 Domain Policy, 트랜잭션 조합은 Service, 최종 동시성 방어는 DB에 배치했다.

## 중단 조건

- preflight가 실제 활성 중복 데이터를 발견한다.
- 동일 시각이 아닌 수업 구간 중복 정책이 필요하다.
- 기존 중복 데이터를 자동 병합하거나 삭제해야 완료할 수 있다.
- 같은 원인의 검증 실패가 세 번 반복된다.
