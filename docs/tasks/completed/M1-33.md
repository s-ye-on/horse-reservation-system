# M1-33: 과거 미처리 출석 조회

## 상태

`COMPLETED`

## 목표

수업일이 지난 `confirmed` 예약도 관리자가 완료 또는 노쇼 처리할 수 있게 출석 화면에 제공한다.

## 담당

`frontend`

## 선행 작업

- M1-24 완료
- M1-16A 완료

## 입력 문서

- [MVP 1 제품 범위](../../product/mvp-1.md)의 수업 완료와 노쇼 처리
- [운영 정책](../../product/policies.md)의 관리자 예약 조회

## 허용 범위

- `frontend/apps/web/src/features/admin-attendance/**`
- `backend/src/main/java/com/horse/reservations/application/**`
- `backend/src/test/java/com/horse/reservations/presentation/AdminReservationQueryApiTest.java`
- `mise.toml`
- `docs/tasks/**`

## 제외 범위

- 100건 초과 페이지 처리
- 예약 이력 전용 화면과 일괄 완료
- 완료·노쇼 상태 전이 정책 변경
- 관련 없는 UX 개선과 전역 스타일 변경

## 완료 조건

- [x] 오늘 이전의 `confirmed` 예약이 출석 처리 대상에 포함된다.
- [x] 일반 관리자 예약 조회의 기본 오늘 이후 정책은 유지된다.
- [x] 기존 완료·노쇼 요청 계약을 변경하지 않는다.
- [x] 검증 명령이 모두 종료 코드 0으로 성공한다.

## 검증 명령

```bash
mise tasks --all
mise run verify:m1-33
mise run verify:changed
```

## 검증 증거

| 명령 | 종료 코드 | 핵심 결과 |
|---|---:|---|
| `mise tasks --all` | 0 | M1-33 검증 task 등록 확인 |
| `mise run verify:m1-33` | 0 | 관리자 날짜 필터와 출석 API 호출 회귀 통과 |
| `mise run verify:changed` | 0 | 문서, 백엔드, API 계약, 웹, 모바일 전체 변경 검증 통과 |

## 완료 증거

- 출석 조회가 `lessonDateFrom=1970-01-01`을 명시해 과거 `confirmed` 예약을 포함한다.
- 일반 관리자 예약 조회는 날짜가 없을 때 오늘 이후만 반환하는 기존 정책을 유지한다.
- 완료와 노쇼 API 계약 및 상태 전이는 변경하지 않았다.

## 중단 조건

- 과거 미처리 예약과 과거 예약 이력의 제품 구분이 충돌한다.
- 100건 제한 개선 없이는 완료 조건을 검증할 수 없다.
- 생성 API 계약 변경이 필요하지만 OpenAPI 재생성을 허용할 수 없다.
