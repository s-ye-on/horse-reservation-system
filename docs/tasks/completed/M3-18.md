## Completion Evidence

- 실제 MySQL fixture에서 지난 승인대기를 자동 만료하고 회원 지난 예약에 노출한다.
- 회원 예정 예약은 변경·취소 링크를 제공하고 만료 예약은 행동 링크를 제공하지 않는다.
- 관리자는 지난 미처리 확정 예약만 단건·일괄 처리 대상으로 사용할 수 있다.
- 시작 전 확정 예약은 완료·노쇼 CTA 없이 서버 차단 사유를 표시한다.
- E2E 인증은 개발용 보안 우회 없이 실제 서명 JWT와 Spring Security 검증을 사용한다.

## 중단 조건
