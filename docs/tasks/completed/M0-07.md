# M0-07: CI 기본 품질 게이트

## 상태

`DONE`

## 목표

GitHub의 새 checkout에서 프로젝트 도구와 의존성을 설치하고 전체 품질 게이트를 재현한다.

## 담당

`dev-workflow`

## 선행 작업

- M0-06 완료

## 입력 문서

- [MVP 0 Backlog](../mvp-0.md)의 `M0-07`
- [검증 명령 계약](../verification-contract.md)의 `verify:all`
- [기술 스택 ADR](../../architecture/adr-002-technology-stack.md)의 mise 결정

## 허용 범위

- `.github/workflows/ci.yml`
- `mise.toml`
- `scripts/harness-self-check.sh`
- `docs/tasks/active/M0-07.md`
- `docs/tasks/completed/M0-07.md`

## 제외 범위

- 배포, 릴리스, 환경 승격
- 브랜치 보호와 GitHub 저장소 설정 자동화
- 외부 비밀값과 운영 인프라
- 병렬 job 분할과 원격 빌드 캐시

## 완료 조건

- [x] push와 pull request에서 읽기 전용 권한의 CI가 실행된다.
- [x] mise가 고정된 Java·Node·pnpm·actionlint를 설치한다.
- [x] 의존성 설치 후 `mise run verify:all`을 실행한다.
- [x] workflow 정적 검사와 새 checkout 전체 검증이 성공한다.

## 검증 명령

```bash
mise tasks --all
mise run verify:m0-07
mise run verify:all
```

## 검증 증거

| 명령 | 종료 코드 | 핵심 결과 |
|---|---:|---|
| `mise tasks --all` | 0 | `verify:m0-07` 존재 확인 |
| `mise run verify:m0-07` | 0 | actionlint·하네스·Compose 검사 통과 |
| `mise run verify:all` | 0 | 루트 전체 품질 게이트 통과 |
| clean checkout `mise run install && mise run verify:all` | 0 | 로컬 전용 파일 없이 전체 검증 통과 |

## 중단 조건

- CI가 저장소 쓰기 권한이나 운영 secret을 요구한다.
- 새 checkout에서 로컬 전용 파일이 없으면 검증할 수 없다.
- CI가 프로젝트의 `verify:all`과 다른 검증 경로를 사용한다.
- 배포 또는 릴리스 설정이 필요하다.
