- 규칙 완화에 API 응답 또는 예외 처리 런타임 변경이 필요하다.
- 책임별 분리 후 기존 규칙 중 하나라도 자동 검증할 수 없다.
- task 범위 밖의 제품 기능 또는 패키지 이동이 필요하다.
- `backend:convention`이 새 테스트를 자동으로 포함하지 못한다.
