## 완료 조건

- [x] 관리자는 활성 예약의 책임, 쿠폰 처리, 500자 이하 필수 메모를 지정해 즉시 `cancelled`로 전이한다.
- [x] preview는 책임별 권장 쿠폰 처리를 반환하며 실행 요청의 명시적 선택을 변경하지 않는다.
- [x] 쿠폰 예약은 `deduct|return`, 1회 결제는 `none`만 허용한다.
- [x] 쿠폰 처리, 예약 상태와 추가 전용 감사 이력이 한 트랜잭션에서 한 번만 반영된다.
- [x] 관리자 권한과 잘못된 상태·입력 조합을 API 테스트로 검증한다.
- [x] 검증 명령이 모두 종료 코드 0으로 성공한다.

## Completion Evidence

- 관리자 취소 preview가 책임별 권장 쿠폰 처리를 서버 정책 판정기로 반환한다.
- 실행 시 관리자가 선택한 허용 쿠폰 처리를 그대로 적용하고 예약·쿠폰·감사 로그를 한 트랜잭션에서 처리한다.
- 쿠폰 예약의 차감·반환, 1회 결제의 `none`, 필수 메모, 권한, 멱등성을 통합 테스트로 검증했다.
- OpenAPI와 생성 TypeScript 계약에서 책임·쿠폰 처리·메모가 필수 입력임을 확인했다.
- `backend/conventions/review.md` 체크리스트와 독립 QA 리뷰를 통과했다.

## 중단 조건

- 관리자 취소가 외부 결제 환불 성공을 필수 조건으로 요구한다.
- 취소 완료 후 관리자 재정의나 되돌리기가 필요하다.
- 기존 예약 또는 쿠폰 감사 이력을 수정·삭제해야 한다.
- 완료 조건을 자동 검증할 수 없다.
