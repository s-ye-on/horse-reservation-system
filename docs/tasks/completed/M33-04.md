# M33-04 Completion Evidence

## 상태

`DONE`

## 목표

M33-01의 월간 완료 기승 통계 API와 M33-03 generated TypeScript client를 사용해 관리자가
조회 월과 기승 종류별 운영 실적, 총 기승 횟수와 공동 최다 기승 회원 전체를 확인하는 반응형 Web
화면을 제공한다.

## 구현 계약

- 관리자 메뉴에 `월간 기승 현황` 진입점을 추가하고
  `/admin/monthly-ride-statistics`를 기존 ADMIN route guard 아래에 배치했다.
- 기본 조회 월은 브라우저 시각을 `Asia/Seoul`로 해석한 현재 월이며, 이전 달·다음 달·월 직접
  선택과 `이번 달` 복귀를 제공한다.
- 기승 종류는 `전체 기승`, `일반 기승`, `마장마술`, `장애물`의 한글 선택지로 제공한다.
  내부 `ALL`, `GENERAL`, `DRESSAGE`, `JUMPING` 값은 API query에만 사용하고 화면에 노출하지 않는다.
- 월이나 종류가 바뀌면 두 값을 포함한 TanStack Query key로 Backend 결과 전체를 다시 조회한다.
- 총 완료 기승 횟수, 최고 완료 횟수와 `leaders`를 generated response 그대로 표시한다. Frontend는
  완료 여부, 월 귀속, RidingClass 분류, 총계나 공동 1위를 다시 계산하지 않는다.
- 최고 회원이 여러 명이면 `공동 최다 기승 회원`으로 전체를 표시한다. 0건이면 총·최고 횟수 0과
  별도 empty state를 표시하며 가짜 회원을 만들지 않는다.
- 최초 loading, API error와 0건을 서로 다른 상태로 표시하고 오류에는 재시도 동작을 제공한다.
- 320px에서는 월 조작과 기승 종류 선택, 지표와 회원 목록을 단일 열로 배치해 가로 넘침 없이
  핵심 조회 동작을 유지한다.
