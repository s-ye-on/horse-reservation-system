# M32-01 Completion Evidence

## 목표

FamilyGroup, membership와 관리자 감사 원장의 DB 스키마를 만들고 회원별 활성 membership을
MySQL 제약으로 하나만 허용한다.

## 선행 작업

- M32-00 완료 및 Special Approval 정책 정정 커밋 반영
- ADR-018 FamilyGroup·membership·감사 불변식 확정

## 구현

- `family_groups`
  - 안정적인 BIGINT ID와 중복 가능한 필수 이름
  - `ACTIVE`, `DISSOLVED` lifecycle과 해제 시각 일관성 제약
  - membership이 없는 빈 ACTIVE 그룹 허용
- `family_memberships`
  - 그룹과 회원의 역사적 membership 행을 보존
  - `ended_at IS NULL`인 회원 ID를 generated column으로 노출하고 UNIQUE 제약 적용
  - 종료된 membership 이후 다른 그룹의 신규 active membership 허용
- `family_group_audit_logs`
  - 그룹 생성·구성원 추가·제거·그룹 해제 action
  - 관리자 subject, 시각, 전후 JSON 상태와 필수 사유
  - 수정 시각 없이 append-only로 사용하는 감사 행 구조
- M32-02 관리자 Command/API와 M32-03 가족 Coupon 로직은 구현하지 않았다.

## DB 불변식

- 회원별 active membership은 최대 하나다.
- ACTIVE FamilyGroup의 구성원 수는 0일 수 있다.
- 그룹 해제는 `DISSOLVED` 상태와 `dissolved_at`을 함께 기록한다.
- membership 종료는 과거 행을 삭제하지 않고 `ended_at`을 기록한다.
- 감사 action별 대상 회원과 전후 상태 shape, 관리자 subject와 필수 사유를 DB CHECK로 검증한다.
