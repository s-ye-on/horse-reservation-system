## 완료 증거

- 관리자 홈에 `/admin/schedule-closures` 진입점을 추가하고 날짜 휴무와 개별
  TimeSlot 휴강을 탭으로 분리했다.
- 날짜 휴무는 영향 예약을 ID 순으로 고정해 표시하고 CLOSING 시작, 예약별 전용
  취소, 부분 실패 재시도, CLOSED 확정과 CLOSING 취소를 제공한다. 활성 예약 0건의
  즉시 CLOSED 경로도 서버의 `startClosing` 원자적 재검사를 사용한다.
- 개별 휴강은 고정 Impact 분모와 해결 상태를 유지하고 시작, 예약별 전용 취소,
  완료, 처리 전 철회와 완료 후 재개를 제공한다. 재개 후에는
  `adminClosed=false`와 다른 마감 원인을 구분해 표시한다.
- Coupon `RETURN`·1회 결제 `NONE`, `changed=false`, 이동 해결, 409·503 재조회,
  중복 제출 방지와 구조화 오류를 화면에 반영했다.
- 독립 검토에서 발견한 즉시 CLOSED Command 오매핑, modal 뒤 오류 복구 UI,
  재개 상태 오표시, 최초 역방향 focus trap과 성공 문구 불일치를 수정했다.
- 실제 Chromium 320x800에서 날짜 패널, 확인 dialog와 TimeSlot 패널의 가로
  overflow 및 viewport 포함 여부를 자동 검증한다.
- PM, Architecture, Frontend/QA 독립 재검토 결과 HIGH 또는 MEDIUM finding 없이
  `GO`를 받았다.

- 날짜 OPEN, CLOSED 날짜의 신규 재개 정책, 연락 상태·메모·담당자 저장, 알림과
