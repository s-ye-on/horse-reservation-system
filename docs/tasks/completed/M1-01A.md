## 제외 범위

- 회원 가입·로그인·관리자 회원 수정 API
- 예약 가능 클래스 계산 및 응답 API
- 예약·쿠폰·정원 스키마
- 기존 Flyway migration 변경 또는 데이터 변환
- 관련 없는 리팩터링과 의존성 변경

## 완료 조건

- [x] Flyway가 회원 테이블과 JWT 주체 고유 제약을 생성한다.
- [x] 회원 Entity가 기승 횟수와 특수 클래스 승인 상태를 유효한 기본값으로 영속화한다.
- [x] Repository가 JWT `sub`에 대응하는 인증 주체로 회원을 조회한다.
- [x] MySQL Testcontainers 통합 테스트와 검증 명령이 모두 종료 코드 0으로 성공한다.

## 중단 조건

- 회원 필드 또는 JWT 주체 매핑이 입력 문서와 충돌한다.
- 기존 migration을 수정하거나 비가역 데이터 변환이 필요하다.
- 허용 범위 밖의 애플리케이션 API 구현이 필요하다.
- MySQL 기반 Repository 조회를 자동 검증할 수 없다.

## Completion Evidence

- Flyway V2가 `members` 테이블과 `auth_subject` 고유 제약을 생성한다.
- JPA `Member`와 `MemberRepository.findByAuthSubject`가 MySQL에서 검증됐다.
- JWT에는 회원 상태를 넣지 않고 `sub`와 `auth_subject`를 연결한다는 계약을 도메인 문서에 기록했다.
