# M3-14: 승인대기 만료 상태와 정리 Job

## 상태

`COMPLETED`

## 목표

점유를 원자적으로 반환한다.

- 예약·쿠폰 관련 backend 구현과 테스트

## Completion Evidence

- Flyway V14와 `ReservationStatus`에 비점유 종료 상태 `approval_expired`를 추가했다.
- 승인대기 만료 Service가 예약 잠금, 상태 전이와 쿠폰 임시 점유 반환을 한 트랜잭션에서 처리한다.
- 자동 Scheduler와 관리자 수동 API가 동일한 만료 Service와 운영 작업 로깅을 사용한다.
- 입금대기는 결제 마감과 수업 시작 중 빠른 경계를 사용하며 Aggregate에서 다시 검증한다.
- 범위 잠금 데드락을 후보 ID 조회 후 ID 순 개별 비관적 잠금으로 해소했다.
- 기존 상태 요약 API가 새 종료 상태를 0건까지 포함하도록 회귀 테스트를 갱신했다.

## 중단 조건

- 기존 이력을 손상하는 migration이 필요하다.
- 쿠폰 점유 반환을 예약 상태 전이와 같은 트랜잭션에 둘 수 없다.
- 같은 원인의 검증 실패가 세 번 반복된다.
