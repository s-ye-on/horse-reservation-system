# M34-02A Completion Evidence

## 상태

`DONE`

## 목표

retired TEMPLATE TimeSlot을 일반 회원 예약 가능 시간과 관리자 주간 운영 캘린더에서 제외한다.

## 구현 계약

- 회원 예약 가능 시간 조회는 `source = TEMPLATE`이면서 `templateInactiveClosed = true`인
  occurrence를 반환하지 않는다.
- 관리자 주간 운영 캘린더는 서울 현재 시각 기준 아직 시작하지 않은 retired TEMPLATE occurrence를
  반환하지 않는다. 이미 시작했거나 과거인 occurrence는 운영 기록으로 유지한다.
- `adminClosed`, `recurringHolidayClosed` 및 MANUAL TimeSlot은 기존 마감 의미와 함께 계속 반환한다.
- retired occurrence에 미래 점유 Reservation이 남아 있어도 일반 주간 캘린더에는 다시 노출하지 않는다.
  해당 Reservation은 M34-02의 Template별 미래 점유 Reservation read model에서 계속 조회한다.
- API response schema와 Web 표현은 변경하지 않고 Backend query 경계에서 provenance를 구분한다.

## Query와 시간 경계

- 회원 조회는 요청 일자와 retirement provenance를 한 번의 repository query로 제한한다.
- 관리자 조회는 기존 월요일부터 일요일 범위 query에 서울 현재 일자와 시각을 적용한다.
- 현재 시각과 같은 시작 시각은 이미 시작한 occurrence로 보존하며, 그보다 늦은 retired occurrence만
  일반 주간 캘린더에서 제외한다.
- 기존 날짜 범위 query와 Reservation 일괄 조회 구조를 유지하므로 슬롯이나 예약 수에 따른 N+1을
  추가하지 않는다.
