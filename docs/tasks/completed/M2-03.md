## 제외 범위

- 마감 후 무료 변경권이 없는 평일 당일 변경
- 주말 당일 차단 정책
- 예약 취소와 쿠폰 차감·반환
- 변경 화면과 관리자 예외 정책
- 관련 없는 리팩터링, 라이브러리 교체, 포맷 전체 변경

## 완료 조건

- [x] 마감 후 쿠폰 예약은 연결 쿠폰의 무료 변경권이 남아 있을 때 날짜·시간을 변경하고 `free_change_used`를 true로 만든다.
- [x] 쿠폰 사용 이력과 예약 변경 이력에 `free_change_used`가 한 번만 추가되며 동일 대상 재시도는 상태와 이력을 다시 변경하지 않는다.
- [x] 1회 결제 예약과 무료 변경권을 이미 사용한 쿠폰 예약의 마감 후 변경은 거부한다.
- [x] 같은 쿠폰의 동시 변경 요청은 무료 변경권을 하나만 소비하며 실패 요청의 예약·정원은 유지한다.
- [x] 검증 명령이 모두 종료 코드 0으로 성공한다.

## Completion Evidence

- Coupon aggregate가 무료 변경권을 한 번만 소비하고 중복 사용을 도메인 예외로 차단한다.
- 마감 후 변경은 `TimeSlot → Coupon → Reservation → 대상 점유` 잠금 순서로 같은 쿠폰의 동시 요청을 직렬화한다.
- 성공 시 쿠폰 사용 이력과 예약 변경 이력에 `free_change_used`를 추가하며 동일 대상 재시도는 이력을 늘리지 않는다.
- 정원 충돌, 1회 결제, 이미 사용한 무료권은 예약 일정·쿠폰·이력을 변경하지 않는다.
- `backend/conventions/review.md`의 Architecture, DDD, Exception, Code Style, Package, Test 항목을 점검했다.

## 중단 조건

- 무료 변경권을 쿠폰이 아닌 예약 단위로 저장해야 한다는 요구가 생긴다.
- 같은 쿠폰의 동시 사용을 하나의 트랜잭션과 잠금으로 보호할 수 없다.
- 기존 쿠폰 사용 또는 예약 감사 이력을 수정·삭제해야 한다.
- 완료 조건을 자동 검증할 수 없다.
