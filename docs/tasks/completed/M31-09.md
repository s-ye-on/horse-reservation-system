## 정책 경계

- 관리자 수동 예약은 `POST /api/admin/reservations`로만 생성하며 `ROLE_ADMIN`만
  호출한다.
- 관리자는 회원의 3시간 예약 마감을 우회하지만 `now >= lessonStartAt`이면 거부한다.
- 과거 수업은 허용하지 않는다.
- 사용 가능한 본인 Coupon이 있으면 기존 결정적 순서로 자동 선택하고 1회 점유한 뒤
  `confirmed`로 생성한다.
- 사용 가능한 Coupon이 없으면 `pending_payment`로 생성한다.
- `paymentDueAt`은 생성 후 2시간과 수업 시작 시각 중 빠른 시각이다.
- ConfigGuard, ScheduleDate, TimeSlot 마감, 정원, 클래스 자격과 동일 회원 overlap을
  기존 잠금 순서로 검증한다.
- 관리자 생성 사유는 필수이며 예약 감사 이력에 관리자 JWT subject와 함께 저장한다.
- M31-08 원장에 관리자 전용 operation을 추가하며 별도 멱등 저장소를 만들지 않는다.

## Completion Evidence

- `POST /api/admin/reservations`는 `ROLE_ADMIN`, 필수 `Idempotency-Key`,
  `memberId`, `timeSlotId`, `classType`, 필수 사유를 받는다.
- 관리자 operation은 M31-08의 원장을 재사용하고 회원 operation과 scope를 분리한다.
  대상 회원, TimeSlot, 클래스와 정규화된 사유를 fingerprint에 포함한다.
- 관리자 생성은 회원 생성과 같은
  `Config SHARE -> ScheduleDate -> member-day guard -> TimeSlot -> overlap -> Coupon`
  순서를 사용한다. 관리자는 회원 예약 마감만 우회하며 수업 시작 시각부터는 거부된다.
- 유효한 본인 Coupon은 기존 만료일 우선 결정적 순서로 선택한다. 같은 transaction에서
  1회 점유와 `confirmed` 원장을 기록하고 Reservation을 `confirmed`로 전이하지만
  잔여 횟수는 수업 완료 전까지 차감하지 않는다.
- Coupon이 없으면 생성 후 2시간과 수업 시작 시각 중 빠른 `paymentDueAt`을 가진
  `pending_payment` 예약을 생성한다.
- V34는 기존 migration을 수정하지 않고 `admin_reservation_created` 감사 CHECK를
  추가한다. V33 upgrade와 fresh V34에서 기존 감사 보존과 신규 불변식을 검증했다.
- 관리자 생성 감사는 관리자 인증 주체, 필수 사유, 대상 예약을 append-only로 남기며
  조회 응답은 연결된 Coupon과 입금 마감 정보를 제공한다.
- 응답 직렬화 실패는 Reservation, Coupon 점유·원장, 관리자 감사와 멱등성 원장을 모두
  rollback한다. 회원과 관리자 교차 요청의 실제 MySQL 경쟁에서도 활성 예약과 Coupon
  점유는 한 번만 남는다.
- OpenAPI와 생성 Client는 `createAdminManualReservation`, 필수
  `Idempotency-Key` Header와 구조화된 요청·응답을 제공한다.
- 독립 Architecture와 DB 재검토는 모두 `GO`이며 HIGH·MEDIUM finding은 0건이다.
- `backend/conventions/review.md` 기준으로 Controller DTO 경계, Entity 상태 변경,
  BusinessException 계층, feature package와 한글 테스트 이름을 확인했다.

## 남은 위험

- 외부 API의 `paymentDueAt`과 감사 시각을 RFC3339 offset으로 통일하는 작업은
  M31-12 범위다. 현재 M31-09 정책과 충돌하지 않지만 웹·Expo 공통 계약 확정 전까지
  시간대 없는 문자열이 유지된다.
- 관리자 수동 예약 웹 화면, 가족 Coupon 후보와 관리자 Coupon 직접 선택은 제외
  범위이며 이번 API에는 포함하지 않았다.
