## 구현 결정

- 기본 월요일 규칙의 `effectiveFrom`은 모든 지원 운영일을 포괄하는
  `1970-01-01`, `effectiveTo`는 NULL로 둔다.
- V26 실행 전에 활성 월요일 규칙이 이미 있으면 기존 운영 설정을 존중해 기준 데이터를
  추가하지 않는다.
- V26이 기준 데이터를 추가하면 이를 설정 변경으로 취급해 guard를 SYNCING으로 전환하고
  `pendingVersion = activeVersion + 1`과 감사 로그를 같은 migration에 반영한다.
- 영향 집계의 활성 예약 SSOT는 generated `active_slot_guard = 1`을 사용한다.

## Completion Evidence

### 구현

- `RecurringHolidayRuleService`가 설정 guard를 `FOR UPDATE`로 잠근 뒤 ACTIVE와
  expected version을 검증하고 정기 휴일 변경, SYNCING 시작과 감사 로그를 한
  트랜잭션에 반영한다.
- 생성·변경·활성화·비활성화는 물리 삭제 없이 도메인 메서드로 상태를 변경한다.
- 같은 요일의 활성 기간 겹침은 종료일 NULL을 `9999-12-31`로 해석하고 양 끝 날짜를
  포함해 검사한다. 경계·무기한·동시 등록 MySQL 테스트를 추가했다.
- 영향 미리보기는 이전 설정, 변경 설정과 두 범위의 distinct 합계를 나누어
  영향 날짜·TEMPLATE TimeSlot·`active_slot_guard = 1` 예약 수를 제공한다.
- V26은 활성 월요일 규칙이 없을 때만 기본 규칙을 추가하며 guard SYNCING 전환,
  pending version, 영향 건수 감사 로그를 같은 migration 트랜잭션에 반영한다.
  감사 로그 쓰기 실패 시 전체 변경이 롤백됨을 검증했다.

### 독립 검토

- PM: migration 감사 로그의 영향 건수 누락과 변경 전·후 영향 구분 부족을 지적했다.
  V26 감사 metadata에 세 영향 건수를 추가하고, 미리보기를 이전·변경·합계로 분리했다.
- Architecture: R06 전환을 막는 HIGH/MEDIUM 문제는 없다고 판정했다. 다만 V26이
  guard를 SYNCING으로 남기므로 R05를 단독 배포하면 안 되며, 설정 완료·실패·재시도
  생명주기를 구현하는 R06과 함께 배포해야 한다.
- DB: migration 원자성 실패 경로와 R05 gate의 잠금 테스트 누락을 지적했다.
  migration rollback 테스트와 `ScheduleLockingIntegrationTest`를 R05 전용 gate에
  추가했다. 겹침 조회가
  `idx_recurring_holiday_rules_day_active_dates`를 사용하는 EXPLAIN도 검증했다.

### 자기 점검

- Controller 또는 공개 API를 추가하지 않았고 Application Service가 트랜잭션과
  orchestration만 담당한다.
- Entity 상태는 `change`, `activate`, `deactivate`, `beginSynchronization`으로
  변경하며 public setter를 추가하지 않았다.
- 새 업무 예외는 `ScheduleException`과 `SCHEDULE_*` 코드를 사용한다.
- Command, View와 영향 모델은 record이며 기존 V1~V25 migration과 기존
  Template·TimeSlot을 수정하지 않았다.

## 남은 위험과 후속 소유

- R05와 V26은 설정을 SYNCING으로 전환하는 시작 계약만 제공한다. 부분 적용 재개,
  실패 기록, 전체 horizon 확인과 ACTIVE 복귀는 M31-R06이 소유한다. R06 없이 R05를
  단독 배포하지 않는다.
- 영향 집계는 최대 3개월 horizon으로 제한되지만 날짜 범위와 OR 조건을 포함한
  `COUNT(DISTINCT ...)`이므로 데이터 규모가 커지면 실행 계획을 다시 측정한다.
- R04와 R05의 영향 결과 모델은 아직 내부 계약이다. 공개 API를 만드는 M31-R11에서
  일관된 응답 구조로 정규화한다.
