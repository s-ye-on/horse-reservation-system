## Completion Evidence

- Aggregate가 기존 Command 검증 메서드로 행동별 허용 여부와 `ExceptionCode` 차단 사유를 계산한다.
- 회원·관리자 조회가 동일한 시각 스냅샷으로 `displayGroup`과 다섯 행동 판정을 반환한다.
- 회원 예약은 예정 오름차순 후 지난 예약 내림차순으로 서버에서 정렬된다.
- OpenAPI와 TypeScript API Client에 `ReservationActionsResponse` 계약을 반영했다.

- 조회와 Command가 동일한 도메인 판정기를 공유할 수 없다.
- 인증 주체별 행동 정의가 제품 정책과 충돌한다.
- 같은 원인의 검증 실패가 세 번 반복된다.
