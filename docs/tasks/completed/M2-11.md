## Completion Evidence

- 전날 21시 경계와 평일·주말 분기는 고정 `Clock` 백엔드 테스트로 항상 재현한다.
- 실제 Spring Boot, MySQL, JWT, React 화면을 연결한 E2E 5개가 마감 전·후 변경, 무료 변경권, 실행일 당일 변경, 회원 취소, 관리자 취소를 검증한다.
- 각 실행 후 예약 상태와 일시, 쿠폰 잔여·점유·무료 변경권, 쿠폰 사용 및 예약 감사 로그를 SQL snapshot으로 확인한다.
- E2E에서 발견한 소문자 timing 표시 오류와 취소 성공 결과가 즉시 덮이는 오류를 회귀 테스트와 함께 수정했다.
- 제외 범위인 모바일 흐름, 외부 결제 환불, 공휴일 정책은 구현하지 않았다.

## 중단 조건

- 행렬을 재현하려면 운영용 Clock 또는 제품 API를 변경해야 한다.
- 기존 정책 테스트와 실제 API 결과가 충돌한다.
- E2E를 위해 운영 데이터 제약을 우회해야 한다.
- 완료 조건을 자동 검증할 수 없다.
