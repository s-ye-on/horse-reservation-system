# M2-10: 관리자 예약 변경·취소 화면

## 상태

`COMPLETED`

## 목표

관리자가 활성 예약을 다른 시간대로 변경하거나 취소 책임, 권장 쿠폰 처리와 최종 처리, 필수 메모를 확인해 취소한다.

## 담당

`frontend`

## 선행 작업

- M2-07 완료

## 입력 문서

- [MVP 2 Backlog](../mvp-2.md)의 `M2-10`
- [운영 정책](../../product/policies.md)의 `예약 변경`, `예약 취소`
- [API 초안](../../architecture/api.md)의 관리자 변경·취소 API

## 허용 범위

- `frontend/apps/web/src/features/admin-reservations/**`
- `docs/tasks/active/M2-10.md`, `docs/tasks/completed/M2-10.md`
- `mise.toml`의 `verify:m2-10` 등록

## 제외 범위

- 결제 환불 자동화
- 예약 변경·취소 정책 또는 API 계약 변경
- 관리자 예약 조회의 페이지네이션 개선
- 모바일 앱 화면
- 관련 없는 리팩터링과 디자인 시스템 교체

## 완료 조건

- [x] 활성 예약에만 시간 변경과 취소 작업을 제공한다.
- [x] 관리자는 기존 클래스를 유지한 채 열린 대상 시간대와 필수 메모로 예약을 변경한다.
- [x] 취소 책임을 선택하면 서버 권장 쿠폰 처리를 표시한다.
- [x] 예약 유형별 허용 범위 안에서 최종 쿠폰 처리를 재정의하고 필수 메모로 취소한다.
- [x] 성공 시 운영 목록을 갱신하고 정책 충돌, 권한 오류, 모바일 폭을 테스트한다.
- [x] 검증 명령이 모두 종료 코드 0으로 성공한다.

## 검증 명령

```bash
mise tasks --all
mise run verify:m2-10
mise run backend:convention
mise run verify:changed
```

## 검증 증거

| 명령 | 종료 코드 | 핵심 결과 |
|---|---:|---|
| `mise tasks --all` | 0 | `verify:m2-10` 등록 확인 |
| `mise run verify:m2-10` | 0 | web lint, typecheck 및 13개 파일 103개 테스트 통과 |
| `mise run backend:convention` | 0 | 백엔드 아키텍처·코딩 컨벤션 통과 |
| `mise run verify:changed` | 0 | backend, OpenAPI, web, mobile 전체 변경 검증 통과 |

## 완료 증거

- 관리자 운영 목록에 확정 예약을 포함하고 상태별 허용 작업을 분리했다.
- 열린 시간대 변경과 책임별 취소 preview, 최종 쿠폰 처리 재정의, 필수 메모 입력 흐름을 구현했다.
- 성공 후 목록 갱신, `403`/`409` 오류 안내, 320px 화면의 작업 노출을 자동 테스트로 검증했다.
- 제외 범위인 결제 환불 자동화, 페이지네이션 개선, 모바일 화면은 구현하지 않았다.

## 중단 조건

- 관리자 화면에서 예약 클래스나 결제 방식을 변경해야 한다.
- 서버 preview가 예약 유형에 허용되지 않는 쿠폰 처리를 권장한다.
- 기존 변경·취소 API 계약을 호환되지 않게 수정해야 한다.
- 완료 조건을 자동 검증할 수 없다.
