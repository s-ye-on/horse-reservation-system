## 최종 계약

### FamilyGroup과 Coupon

- 안정적인 Group ID가 identity이고 중복 가능한 필수 이름을 사용하며 대표 회원은 두지 않는다.
- ADMIN만 생성·구성원 추가·제거·해제를 수행한다.
- 회원별 active membership은 최대 하나고 빈 ACTIVE 그룹을 허용한다.
- 제거는 membership만 종료하고 그룹 해제는 모든 active membership을 종료하는 비가역 Command다.
- 전용 transfer는 없으며 제거와 추가 사이 가족이 없는 상태를 허용한다.
- Coupon과 원소유자는 유지하고 active membership이 신규 후보 범위만 확장한다.
- 후보는 `(expiresAt IS NULL) ASC`, `expiresAt ASC`, `createdAt ASC`, `couponId ASC`다.
- 가족 변경 후에도 기존 Reservation·hold·반환 Coupon은 유지하고 사용 시점 관계를 snapshot으로 보존한다.

### Class progression

- 실제 일반 기승 횟수는 사실 기록이고 baseline은 지정 시작 클래스의 최소 threshold를 인정하는 Anchor다.
- baseline 인정분은 `max(0, baselineThreshold - baselineActualRideCount)`로 파생하며 별도
  progression counter는 두지 않는다.
- baseline은 설정·변경·해제할 수 있고 하향·해제는 잘못된 경력 인정 correction이다.
- 시스템 도입 이전 경력은 baseline으로 종결하고 과거 횟수·날짜·기간을 복원하지 않는다.
- 회원별 Horse progression 관리 시작 경계는 write-once이며 최초 baseline 승인 또는 신규 회원
  progression 초기화가 설정한다. baseline 교정·해제와 M32-07은 경계를 다시 쓰지 않는다.
- 특수 승인이 없는 회원에게만 promotion hold를 progressionClass 이하의 안전 상한으로 설정한다.
- hold 중 progression은 계속 누적하고, 해제하면 현재 progressionClass로 즉시 복귀한다.
- 마장마술·장애물 승인 시 승인 직전 progression과 대마장 속보 threshold의 부족분만
  `specialApprovalProgressionCredit`으로 고정한다. threshold나 기존 Horse 완료 횟수를 다시
  더하지 않으며 승인 이후 일반 기승부터 정상 누적한다.
- 특수 기승은 일반 progression에 더하지 않고 구보초보·구보는 정상 threshold로만 열린다.
- 특수 승인 해제는 특수 예약 자격만 제거하며 이미 고정한 progression 인정분을 자동 회수하지 않는다.
- 잘못된 인정의 하향 교정은 모든 특수 승인을 먼저 해제하고 M32-06의 별도 관리자 Command로 수행한다.
- Special Approval과 promotion hold는 동시에 활성화할 수 없고 관리자가 선행 상태를 명시적으로 해제한다.

### Ride count adjustment

- M32-07은 Horse progression 관리 시작 이후 완료 집계의 누락·중복 오류만 정정한다.
- 양수·음수 delta, before, after, 관리자, 시각과 필수 사유를 기록하며 결과는 0 이상이다.
- 시스템 도입 이전 역사 복원, PRE_ANCHOR·POST_ANCHOR 입력과 Anchor 재기준화는 지원하지 않는다.

## Special Approval 정책 정정

M32-00 완료 후 Special Approval을 단순 예약 자격으로만 해석한 계약을 정정했다. 승인 직전
progression을 `P`, 대마장 속보 threshold를 `S`로 두고 부족분 `D=max(0,S-P)`만 영속 인정한다.
Baseline은 시스템 도입 이전 경력 요약으로 유지하고, 실제 완료 횟수와 write-once 관리 시작
경계도 변경하지 않는다. 인정분은 일반 기승마다 누적되는 별도 counter가 아니며 승인 해제로
자동 회수되지 않는다. M32-07은 계속 Horse 관리 이후 완료 집계 오류만 정정한다.
