## 완료 조건

- [x] 전날 21:00 이후와 당일이라도 수업 시작 직전이면 신규 예약이 허용된다.
- [x] 정확한 수업 시작 시각과 이후에는 `RESERVATION_LESSON_ALREADY_STARTED`로 차단된다.
- [x] 요청 `Instant`를 `Asia/Seoul`로 변환하며 필수 입력의 도메인 예외가 검증된다.
- [x] 모든 검증 명령이 종료 코드 0으로 성공한다.

## Completion Evidence

- `ReservationBookingTimePolicy`가 요청 `Instant`를 `Asia/Seoul` 지역 시각으로 변환한다.
- 수업 전날 21:00 이후에도 수업 시작 전이면 허용하여 변경 마감 정책과 분리했다.
- 수업 시작 직전은 허용하고 정각과 이후에는 조회용 차단 사유와 Command 예외를 같은 정책에서 제공한다.
- 필수 날짜, 시작 시각과 신청 시각 누락을 단일 `ExceptionCode` 체계로 검증한다.
- `review.md` 기준 Domain 의존성, 예외, 코딩 스타일과 테스트 규칙을 위반하지 않음을 확인했다.

## 중단 조건

- 신규 예약 생성에 전날 21:00 마감을 다시 적용해야 한다.
- 수업 시작 시각 이외의 신규 예약 마감 정책이 필요하다.
- Domain Policy 구현에 조회·Command API 변경이 필요하다.
- 같은 원인의 검증 실패가 세 번 반복된다.
