# M32-09 Completion Evidence

## 목표

M32-01~08에서 구현한 가족 그룹, 가족 Coupon snapshot, 회원 클래스 progression 계약을 실제 Spring
runtime OpenAPI와 generated TypeScript client에 동기화하고, 관리자 Web의 임시 수동 transport를 생성
Client 기반 경계로 교체한다.

## 동기화 범위

- 가족 그룹 생성·조회·구성원 후보·추가·제거·해제·감사 Page의 operation과 DTO를 공개한다.
- 회원 progression preview·감사 조회와 baseline·promotion hold·특수 승인 인정분·일반 기승 횟수
  Command를 공개한다.
- `FIRST_RIDE`부터 `CANTER`까지 일곱 일반 클래스 enum과 progression/effective class, 실제 횟수,
  baseline Anchor, 특수 승인 인정분, promotion hold 필드를 생성 타입에 반영한다.
- 회원 Coupon 사용 이력에 실제 예약 회원, Coupon 원소유자, 사용 당시 FamilyGroup snapshot을 구분해
  공개한다. 가족 Coupon 후보 선택은 별도 공개 Endpoint가 아니라 기존 예약 Application Service 내부
  계약이므로 새로운 API를 만들지 않는다.
- 기존 회원 특수 승인 API의 필수 관리자 사유와 확장된 회원 응답도 생성 계약에 반영한다.

## OpenAPI와 generated client

- Controller operation ID를 명시해 생성 메서드 이름을 안정화하고 Phase B API에 기존
  `bearerAuth` 계약이 적용되는지 회귀 테스트로 고정한다.
- nullable timestamp, baseline/hold, 가족 감사 snapshot, Coupon 가족 snapshot을 OpenAPI 3.1
  null 계약으로 명시한다.
- 가족 및 progression 감사 snapshot을 이름 있는 response schema로 정규화해 runtime JSON의 필드와
  nullable 계약이 generated type에 그대로 반영되도록 했다.
- runtime에서 생성한 `backend/openapi/horse-api.json`을 원천으로 정식 `typescript-fetch` generator를
  실행했다. generated 파일은 직접 편집하지 않았다.
- `api:check`가 같은 runtime 원천에서 OpenAPI와 Client를 다시 생성해 저장소 결과와 일치함을
  검증한다.

## If-Match / stateToken

- preview `stateToken`은 SHA-256 validator를 큰따옴표로 감싼 quoted strong entity-tag다.
- Web은 생성 Client의 `ifMatch` 인자에 응답값 전체를 넘기며 Client는 같은 값을 `If-Match` Header에
  전달한다. Header의 따옴표를 제거하거나 다시 직렬화하지 않는다.
- 서버는 잠긴 최신 snapshot과 validator를 비교해 stale preview를
  `MEMBER_CLASS_STATE_CONFLICT`로 거부하는 M32-08 정책을 유지한다.
- 기존 API 호출 하위 호환을 위해 Header의 선택성은 유지했으며, M32-08 Web은 preview 후 항상 보낸다.

## Web migration

- 가족 그룹과 회원 progression feature의 수동 `fetch` 및 로컬 전송 DTO/enum을 제거했다.
- 기존 중앙 `bearerApiConfiguration`으로 생성 Query/Command Client를 구성한다.
- 화면용 façade와 오류 메시지 경계는 유지하되 request/response 타입은 generated contract에서
  직접 사용하거나 파생한다. threshold나 progression 계산은 Frontend에 추가하지 않았다.
- 생성 Client의 date-time 역직렬화 결과인 `Date`를 UI와 테스트 fixture에서 일관되게 사용한다.
