# M1-32: 쿠폰 만료 상태 전이와 자동 작업

## 상태

`COMPLETED`

## 목표

유효기간이 지난 쿠폰의 사용 가능 잔여분을 소멸하고 만료 상태와 감사 이력을 멱등적으로 기록한다.

## 담당

`backend`

## 선행 작업

- M1-09A 완료
- M1-17 완료

## 입력 문서

- [운영 정책](../../product/policies.md)의 쿠폰과 정상 점유 fallback
- [도메인 모델](../../architecture/domain-model.md)의 Coupon과 CouponUsageLog

## 허용 범위

- `backend/src/main/java/com/horse/coupons/**`
- `backend/src/test/java/com/horse/coupons/**`
- `backend/src/main/java/com/horse/global/exception/ExceptionCode.java`
- `backend/src/main/resources/application.yml`
- `backend/src/main/resources/db/migration/**`
- `mise.toml`
- `docs/tasks/**`

## 제외 범위

- 관리자 쿠폰 보정·수동 만료 API
- 예약 취소·변경과 알림
- 쿠폰 선택 순서 변경
- 관련 없는 리팩터링, 라이브러리 교체, 포맷 전체 변경

## 완료 조건

- [x] `Asia/Seoul` 기준 만료일 다음 날부터 사용 가능 잔여분이 소멸한다.
- [x] 만료 전에 정상 점유된 횟수는 만료 후에도 완료·차감할 수 있고 반환 시 복구되지 않는다.
- [x] 자동 작업은 재실행과 동시 실행에도 만료 상태와 `expired` 로그를 한 번만 기록한다.
- [x] 검증 명령이 모두 종료 코드 0으로 성공한다.

## 검증 명령

```bash
mise tasks --all
mise run verify:m1-32
mise run backend:convention
mise run verify:changed
```

## 검증 증거

| 명령 | 종료 코드 | 핵심 결과 |
|---|---:|---|
| `mise tasks --all` | 0 | M1-32 검증 task 등록 확인 |
| `mise run verify:m1-32` | 0 | 도메인 경계, MySQL 만료 작업, 회원 쿠폰 조회 회귀 통과 |
| `mise run backend:convention` | 0 | Checkstyle과 컨벤션 테스트 통과 |
| `mise run verify:changed` | 0 | 문서, 백엔드, API 계약, 웹, 모바일 전체 변경 검증 통과 |

## 완료 증거

- 만료일 당일까지는 활성 상태를 유지하고 다음 날 사용 가능한 잔여분만 소멸한다.
- 만료 전에 점유된 횟수는 `remaining_count = held_count`로 보존하며 반환과 사용 시 함께 감소한다.
- 만료 대상 조회를 `FOR UPDATE`로 직렬화하고 예약 없는 `expired` 시스템 로그를 한 번만 저장한다.
- 운영 기본 실행 주기를 1분으로 두어 만료 상태와 조회 표시의 지연을 제한한다.

## 중단 조건

- 정상 점유된 만료 쿠폰 처리 정책과 기존 완료 정책이 충돌한다.
- 이력 무결성을 위해 기존 데이터를 손상하는 migration이 필요하다.
- 만료 기준일을 `Asia/Seoul`로 결정할 수 없다.
