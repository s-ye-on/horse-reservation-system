## 완료 조건

- [x] 활성 예약 카드에서만 변경 화면으로 이동할 수 있다.
- [x] 현재 예약의 클래스는 유지하고 3개월 이내 날짜와 예약 가능한 시간대를 선택한다.
- [x] 선택한 대상의 변경 가능 여부와 예상 쿠폰 처리는 서버 preview 결과로 표시한다.
- [x] 실행 성공 후 새 날짜·시간과 무료 변경권 사용 여부를 표시하고 예약 목록을 갱신한다.
- [x] 로딩·빈 시간대·정책 거부·API 오류·모바일 폭 상태를 테스트한다.
- [x] 검증 명령이 모두 종료 코드 0으로 성공한다.

## 검증 명령

```bash
mise tasks --all
mise run verify:m2-08
mise run backend:convention
mise run verify:changed
```

## 검증 증거

| 명령 | 종료 코드 | 핵심 결과 |
|---|---:|---|
| `mise tasks --all` | 0 | M2-08 검증 task 등록 확인 |
| `mise run verify:m2-08` | 0 | preview API 통합 테스트와 웹 lint/typecheck/test 통과 |
| `mise run backend:convention` | 0 | Checkstyle 및 아키텍처 규칙 테스트 통과 |
| `mise run verify:changed` | 0 | backend, OpenAPI, web, mobile 및 문서 변경 검증 통과 |

## Completion Evidence

- 회원 변경 preview API가 변경 가능 여부, 변경 기준, 예상 쿠폰 처리와 무료 변경권 사용 여부를 반환한다.
- 활성 예약 카드에만 변경 진입점을 표시하고 클래스 고정, 3개월 날짜 제한, 예약 가능한 시간 선택을 제공한다.
- 변경 성공 후 새 수업 일시와 무료 변경권 사용 결과를 표시하고 회원 예약 query를 무효화한다.
- 백엔드 통합 테스트와 프론트 로딩·빈 목록·정책 거부·API 오류·320px 상태 테스트를 추가했다.

## 중단 조건

- 프론트가 서버 정책을 재구현해야만 예상 결과를 표시할 수 있다.
- 예약 변경에서 클래스 또는 결제 방식 변경이 필요하다.
- 기존 변경 API 계약을 호환되지 않게 수정해야 한다.
- 완료 조건을 자동 검증할 수 없다.
