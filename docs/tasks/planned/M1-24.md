## 제외 범위

- 여러 예약의 일괄 완료
- 예약 승인·반려·변경·취소와 만료 복구
- 탑승 횟수 또는 쿠폰 잔여 횟수의 수동 보정
- 생성형 API 클라이언트 직접 수정, 클라이언트 차감 계산, 감사 이력 전체 조회

## 완료 조건

- [ ] 관리자 예약 조회 결과 중 `confirmed` 예약의 회원·수업·결제 방식·쿠폰 요약을 단건 처리 대상으로 표시한다.
- [ ] 일반·마장마술·장애물 완료 요청 후 서버 응답의 `completed` 상태와 쿠폰·탑승 이력 결과를 표시한다.
- [ ] 노쇼는 `deduct`, `return`, `none` 중 서버가 허용한 쿠폰 처리와 필수 메모를 확인받아 제출하고 충돌·중복 제출을 처리한다.
- [ ] 320px 이상 반응형 완료·노쇼·오류 컴포넌트 테스트와 검증 명령이 모두 종료 코드 0으로 성공한다.

## 검증 명령

```bash
mise tasks --all
mise run verify:m1-24
mise run verify:changed
```

## 검증 증거

| 명령 | 종료 코드 | 핵심 결과 |
|---|---:|---|
| `mise tasks --all` | - | READY 단계, 구현 후 `verify:m1-24` 등록을 기록한다. |
| `mise run verify:m1-24` | - | READY 단계, 일반·특수 완료와 노쇼 UI 테스트 결과를 기록한다. |
| `mise run verify:changed` | - | READY 단계, 변경 영역 품질 게이트 결과를 기록한다. |

## 중단 조건

- M1-16A 조회 응답으로 `confirmed` 상태와 클래스·결제·쿠폰 요약을 식별할 수 없다.
- M1-17·M1-18 완료 응답이 실제 쿠폰 처리와 일반·특수 탑승 이력 결과를 확인할 정보를 제공하지 않는다.
- M1-19가 허용 쿠폰 처리 값, 필수 관리자 메모, 멱등 충돌 응답을 명확히 정의하지 않는다.
- 화면 구현에 일괄 처리 API, 클라이언트 도메인 계산 또는 허용 범위 밖 파일 변경이 필요하다.
