## 완료 조건

- [ ] `POST /api/admin/members/{memberId}/coupons`가 `general`, `dressage`, `jumping` 중 하나인 신규 10회권을 대상 회원에게 등록한다.
- [ ] 신규 쿠폰은 총·잔여 10회, 점유 0회, 미사용 변경권, `active`, 첫 사용일·만료일 없음으로 생성된다.
- [ ] `ADMIN` 권한, 존재하지 않는 회원, 잘못된 종류·횟수, 중복 제출 부수 효과를 API·통합 테스트로 검증한다.
- [ ] 검증 명령이 모두 종료 코드 0으로 성공한다.

## 중단 조건

- 외부 구매나 입금 상태를 확인하지 않고는 등록할 수 없다는 새로운 제품 정책이 필요하다.
- 10회권 외 총 횟수 또는 초기 만료일을 관리자가 입력해야 한다는 기존 API 계약이 발견된다.
- 중복 요청 처리에 필요한 멱등성 계약이 기존 API convention과 충돌한다.
- 구현에 회원 수정, 쿠폰 보정 또는 전역 인증 설정 변경이 필요하다.
- 다른 회원에게 쿠폰을 등록하거나 `MEMBER` 권한으로 성공하는 보안 테스트 실패가 발생한다.
