## 완료 조건

- [ ] ADMIN만 확정 전 `pending_admin_approval` 또는 `pending_payment`를 사유와 함께 `rejected`로 전이한다.
- [ ] 정원을 반환하고 쿠폰 예약이면 임시 점유도 해제하며 두 부수 효과를 상태 전이와 함께 커밋한다.
- [ ] `cancelled`와 구분된 관리자·반려 사유 이력을 남기고 중복 요청은 반환을 반복하지 않는다.
- [ ] 검증 명령이 모두 종료 코드 0으로 성공한다.

## 중단 조건

- 반려와 취소를 같은 상태나 같은 API로 합쳐야만 구현할 수 있다.
- 정원 반환 또는 쿠폰 임시 점유 해제가 상태 전이와 분리 커밋된다.
- 반려 관리자와 사유를 현재 모델에 기록할 수 없다.
- 확정·완료·만료 예약의 반려를 허용해야 한다는 요구가 추가된다.
- 허용 범위 밖의 스키마·프론트엔드 변경이 필요하다.
