## 완료 조건

- [ ] 정원 점유 primitive가 마감, 전체 8명, 원형 4명, 관리자 클래스 정원 중 하나라도 초과하는 요청을 거부한다.
- [ ] 정원 해제 primitive가 점유 수를 음수로 만들지 않고 같은 점유를 중복 해제하지 않는다.
- [ ] 동일 시간대 병렬 점유에서 DB 잠금과 단일 트랜잭션으로 허용된 수만 성공하고 해제 후 다시 점유할 수 있음을 MySQL 통합 테스트로 증명한다.

## 중단 조건

- M1-03 저장 모델만으로 전체·원형·클래스 점유를 원자적으로 증감할 수 없다.
- 점유와 해제 primitive에 멱등 키가 필요하지만 소유할 식별 계약이 정의되어 있지 않다.
- 고정된 잠금 순서를 정의하려면 기존 모듈 의존 방향 또는 transaction convention을 바꿔야 한다.
- 원형 클래스 집합이 기존 `RidingClass` 정의에서 식별되지 않거나 제품 문서와 충돌한다.
- 동시성 검증을 실제 MySQL이 아닌 단위 테스트로만 대체해야 한다.
