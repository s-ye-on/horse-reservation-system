# M3-15: 예약 행동 가능 Read Model API

## 상태

`READY`

## 목표

회원·관리자 예약 조회가 표시 그룹과 행동별 허용 여부 및 차단 이유를 독립적으로
제공하도록 OpenAPI 계약을 확장한다.

## 담당

`backend`, `frontend`, `qa`

## 선행 작업

- M3-14 완료

## 입력 문서

- [운영 정책](../../product/policies.md)
- [ADR-013](../../architecture/adr-013-time-based-reservation-lifecycle.md)

## 허용 범위

- 예약 조회 Application·presentation DTO와 테스트
- OpenAPI와 생성 TypeScript API Client
- API 계약 문서
- `docs/tasks/active/M3-15.md`, `docs/tasks/completed/M3-15.md`

## 제외 범위

- Command 정책 변경
- 회원·관리자 화면 구성
- 데이터베이스 schema 변경
- 관련 없는 리팩터링, 라이브러리 교체, 포맷 전체 변경

## 완료 조건

- [ ] `displayGroup`이 수업 시작 시각 기준 `UPCOMING`과 `PAST`를 반환한다.
- [ ] change, cancel, complete, noShow와 관리자 approve가 각각 `allowed`, `blockedReason`을 반환한다.
- [ ] OpenAPI와 TypeScript Client가 최신 계약과 일치한다.
- [ ] 검증 명령이 모두 종료 코드 0으로 성공한다.

## 검증 명령

```bash
mise tasks --all
mise run verify:m3-15
mise run backend:convention

```

## 중단 조건

- 조회와 Command가 동일한 도메인 판정기를 공유할 수 없다.
- 인증 주체별 행동 정의가 제품 정책과 충돌한다.
- 같은 원인의 검증 실패가 세 번 반복된다.
