## 제외 범위

- 예약 신청·승인과 실시간 정원 점유 계산
- 강사·말·실내·야외·원형마장 자동 배정
- 반복 일정 생성과 운영 통계
- 생성형 API 클라이언트 직접 수정, 백엔드 정원 제한 재계산, 전역 디자인 개편

## 완료 조건

- [ ] 날짜별 목록에서 시간대의 마감 여부, 전체 정원, 원형 정원, 클래스별 정원을 조회할 수 있다.
- [ ] 시간대 생성·정원 수정·마감 요청은 해당 관리자 API를 호출하고 성공 후 서버 응답으로 목록을 갱신한다.
- [ ] 전체 8명·원형 4명과 클래스 정원의 입력 오류, 충돌 응답, 권한 거부, 중복 제출 방지가 명확히 표시된다.
- [ ] 320px 이상 반응형 목록·폼·마감 컴포넌트 테스트와 검증 명령이 모두 종료 코드 0으로 성공한다.

## 검증 명령

```bash
mise tasks --all
mise run verify:m1-22
mise run verify:changed
```

## 검증 증거

| 명령 | 종료 코드 | 핵심 결과 |
|---|---:|---|
| `mise tasks --all` | - | READY 단계, 구현 후 `verify:m1-22` 등록을 기록한다. |
| `mise run verify:m1-22` | - | READY 단계, 시간대 생성·수정·마감 UI 테스트 결과를 기록한다. |
| `mise run verify:changed` | - | READY 단계, 변경 영역 품질 게이트 결과를 기록한다. |

## 중단 조건

- M1-04 API에서 조회·생성·수정·마감의 식별자와 요청·응답 계약을 구분할 수 없다.
- 전체·원형·클래스 정원 제한 또는 `is_closed` 의미가 제품·도메인 문서와 충돌한다.
- 수정 충돌과 입력 오류가 같은 응답으로 내려와 사용자가 재시도 여부를 판단할 수 없다.
- 화면 구현에 예약 점유 계산 또는 허용 범위 밖 백엔드·공통 패키지 변경이 필요하다.
