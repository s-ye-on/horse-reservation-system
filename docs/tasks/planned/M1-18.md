# M1-18: 특수 기승 완료 처리

## 상태

`READY`

## 목표

확정된 마장마술 또는 장애물 기승을 완료하고 해당 클래스 이력과 쿠폰 결과를 한 번만 반영한다.

`backend`

## 제외 범위

- 일반 기승 완료 횟수와 일반 등급 증가
- 노쇼, 일괄 완료, 예약 취소·변경
- 특수 클래스 승인 권한 변경과 관리자 화면
- 기존 아키텍처·컨벤션 변경과 관련 없는 리팩터링

## 완료 조건

- [ ] ADMIN만 `confirmed` 마장마술·장애물 예약을 `completed`로 전이하고 정원 점유를 종료한다.
- [ ] 쿠폰 예약은 일치하는 쿠폰 점유 1회를 실제 차감하고 최초 사용일·만료일을 적용하며 1회 결제는 쿠폰을 변경하지 않는다.
- [ ] 마장마술과 장애물 완료 이력을 각각 한 번만 증가시키고 일반 기승 횟수와 등급은 변경하지 않는다.
- [ ] 검증 명령이 모두 종료 코드 0으로 성공한다.

## 검증 명령

mise tasks --all
mise run verify:m1-18
mise run verify:changed

## 중단 조건

- 마장마술·장애물 완료 이력을 구분해 저장할 수 없다.
- 완료 상태, 쿠폰 차감, 클래스별 이력 증가를 한 command 트랜잭션으로 묶을 수 없다.
- 특수 기승 완료가 일반 기승 횟수나 일반 등급을 증가시켜야 한다는 요구가 발견된다.
- 반복·경쟁 요청에서 쿠폰 또는 특수 기승 이력의 중복 반영을 막을 수 없다.
- 허용 범위 밖의 승인 정책·프론트엔드 변경이 필요하다.
