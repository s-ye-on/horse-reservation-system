## 완료 조건

- [ ] `GET /api/timeslots?date=&classType=`가 JWT `sub`의 현재 회원과 `Asia/Seoul` 날짜를 기준으로 조회한다.
- [ ] 회원에게 허용되지 않은 클래스는 예약 가능으로 응답하지 않고, 허용된 클래스는 시간대 ID, 서울 기준 날짜·시각, 마감 여부, 예약 가능 여부, 잔여 정원과 마감·만석 원인을 구분해 응답한다.
- [ ] 본인 조회, 날짜·클래스 입력 검증, 비인증 접근, 마감과 정원 경계가 API 테스트로 검증되며 조회는 정원이나 예약을 변경하지 않는다.
- [ ] 검증 명령이 모두 종료 코드 0으로 성공한다.

## 중단 조건

- M1-02의 예약 가능 클래스 판정을 재사용할 공개 application 경계가 없어 `members` 내부 구현을 직접 참조해야 한다.
- 마감·잔여 정원을 표현할 응답 계약이 기존 OpenAPI 또는 제품 요구사항과 충돌한다.
- 조회 일관성을 위해 정원 점유와 동일한 쓰기 잠금이나 데이터 변경이 필요하다.
- 회원 시간대 조회 구현에 예약 생성, 쿠폰 조회 또는 프론트엔드 수정이 필요하다.
- 현재 회원 외 다른 회원의 등급·승인·시간대 정보가 노출되는 테스트 실패가 발생한다.
