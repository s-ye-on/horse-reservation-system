## 완료 조건

- [ ] M1-02 응답의 현재 등급과 예약 가능 클래스만 필터 선택지로 표시한다.
- [ ] 선택한 클래스와 날짜에 대해 M1-05A 응답의 시간, 마감, 만석, 잔여 정원을 `Asia/Seoul` 날짜 기준으로 표시한다.
- [ ] 예약 가능한 시간대만 신청 화면으로 이동할 수 있고 로딩·빈 날짜·조회 실패·권한 거부 상태가 구분된다.
- [ ] 320px·768px 이상 달력 탐색과 키보드 접근 컴포넌트 테스트 및 검증 명령이 모두 종료 코드 0으로 성공한다.

## 중단 조건

- M1-02 응답이 현재 등급과 서버가 판정한 예약 가능 클래스 목록을 제공하지 않는다.
- M1-05A 응답이 시간대 ID, `Asia/Seoul` 날짜·시간, 마감 여부, 예약 가능 여부 또는 잔여 정원을 제공하지 않는다.
- 만석과 운영 마감을 같은 값으로 내려줘 회원에게 원인을 구분해 표시할 수 없다.
- 화면 구현에 클라이언트 정원 계산, 백엔드 API 변경 또는 생성형 API 클라이언트 직접 수정이 필요하다.
