## 완료 조건

- [ ] ADMIN만 `confirmed` 예약을 `no_show`로 전이하며 `coupon_action`과 관리자 메모를 필수 검증한다.
- [ ] 쿠폰 예약은 허용된 `deduct`, `return`, `none` 결정대로 한 번만 처리하고 1회 결제에는 허용 가능한 조합만 적용한다.
- [ ] 정원 점유 종료, 쿠폰 결과, 관리자·사유 감사 이력을 한 트랜잭션으로 반영하고 반복 요청은 멱등하다.
- [ ] 검증 명령이 모두 종료 코드 0으로 성공한다.

## 중단 조건

- 1회 결제 예약에 허용할 `coupon_action` 조합을 서버 규칙으로 결정할 수 없다.
- `none` 처리 시 기존 쿠폰 점유를 유지할지 해제할지 정책이 필요하다.
- 상태 전이와 정원·쿠폰·감사 이력을 한 command 트랜잭션으로 묶을 수 없다.
- 반복·경쟁 요청에서 쿠폰 결과가 두 번 반영될 가능성을 차단할 수 없다.
- 허용 범위 밖의 일반 취소·결제·프론트엔드 변경이 필요하다.
