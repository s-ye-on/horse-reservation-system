## 완료 조건

- [ ] `GET/POST/PATCH/DELETE /api/admin/timeslots` 계열과 `PUT /api/admin/timeslots/{timeslotId}/capacity`가 API 초안의 관리자 query/command surface를 제공한다.
- [ ] `ADMIN`만 변경할 수 있고 비인증·회원 권한, 중복 날짜·시각, 전체 8·원형 4·클래스 정원 제한 위반을 일관된 오류로 거부한다.
- [ ] 생성·부분 수정·마감·삭제와 존재하지 않는 시간대 처리를 API 통합 테스트로 검증한다.
- [ ] 검증 명령이 모두 종료 코드 0으로 성공한다.

## 중단 조건

- `DELETE`를 물리 삭제, 마감 처리, 이력 보존 중 무엇으로 해석할지 기존 코드나 입력 문서가 서로 다르다.
- 정원 축소 시 이미 점유된 예약을 어떻게 처리할지 결정해야 하지만 점유 데이터가 존재한다.
- API 구현에 예약·쿠폰 모듈 또는 전역 보안 설정 변경이 필요하다.
- OpenAPI 또는 오류 응답 convention을 따르려면 기존 convention 자체를 바꿔야 한다.
- 관리자 권한과 비인증 응답을 자동 검증할 수 없다.
