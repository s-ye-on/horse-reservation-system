# M1-17: 일반 기승 완료 처리

## 상태

`READY`

## 목표

확정된 일반 기승을 완료하고 쿠폰 차감과 회원 일반 기승 횟수를 한 번만 반영한다.

## 제외 범위

- 마장마술·장애물 완료와 노쇼
- 일괄 완료, 예약 취소·변경
- 쿠폰 만료 job과 관리자 화면
- 기존 아키텍처·컨벤션 변경과 관련 없는 리팩터링

## 완료 조건

- [ ] ADMIN만 `confirmed` 일반 기승 예약을 `completed`로 전이하고 정원 점유를 종료한다.
- [ ] 쿠폰 예약은 점유 1회를 실제 차감하며 최초 완료이면 수업일을 `first_used_at`으로 하고 3개월 만료일을 계산하고, 1회 결제는 쿠폰을 변경하지 않는다.
- [ ] 회원의 일반 기승 완료 횟수와 감사 이력을 한 번만 반영하고 반복·경쟁 완료 요청은 멱등하다.
- [ ] 검증 명령이 모두 종료 코드 0으로 성공한다.

## 중단 조건

- 완료 상태와 쿠폰 차감·회원 횟수 증가가 서로 다른 트랜잭션에서 커밋된다.
- 첫 기승일 기준 3개월 만료일 계산 규칙을 현재 날짜 타입으로 일관되게 표현할 수 없다.
- 이미 만료된 쿠폰 점유 예약의 완료 처리 정책을 추가 결정해야 한다.
- 반복·경쟁 요청에서 쿠폰 또는 일반 기승 횟수 중복 반영을 막을 수 없다.
- 일반 완료에 특수 클래스 이력을 함께 변경해야 한다는 요구가 추가된다.
