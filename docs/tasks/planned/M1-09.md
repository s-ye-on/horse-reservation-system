## 완료 조건

- [ ] 임시 점유는 유효한 쿠폰에서 `held_count`를 1 증가시키고 `held` 로그를 같은 트랜잭션에 기록하며 `held_count <= remaining_count`를 유지한다.
- [ ] 해제는 해당 예약의 기존 점유만 한 번 감소시키고 `released` 로그를 기록하며 중복 점유·해제 요청은 추가 부수 효과를 만들지 않는다.
- [ ] 사용 가능 횟수 1회인 같은 쿠폰에 대한 병렬 점유에서 정확히 한 요청만 성공하고 실패 요청은 쿠폰과 로그를 변경하지 않음을 MySQL 통합 테스트로 증명한다.
- [ ] 검증 명령이 모두 종료 코드 0으로 성공한다.

## 중단 조건

- 점유·해제의 멱등성을 식별할 예약 식별자 또는 로그 조회 계약이 없다.
- `held_count`와 사용 로그를 같은 DB 트랜잭션에서 갱신할 수 없다.
- 동시성 보장을 위해 Redis·분산 잠금 또는 architecture 변경이 필요하다.
- `held`·`released` 외 새로운 action 의미를 먼저 결정해야 한다.
- 실제 MySQL 병렬 테스트 없이 인메모리 DB 또는 단위 테스트만으로 완료해야 한다.
