# M3-14: 승인대기 만료 상태와 정리 Job

## 상태

`READY`

## 목표

수업 시작까지 승인되지 않은 쿠폰 예약을 `approval_expired`로 정리하고 정원과 쿠폰 임시
점유를 원자적으로 반환한다.

## 담당

`backend`, `db`, `qa`

## 선행 작업

- M3-13 완료

## 입력 문서

- [운영 정책](../../product/policies.md)
- [예약 상태 머신](../../architecture/reservation-state-machine.md)
- [ADR-013](../../architecture/adr-013-time-based-reservation-lifecycle.md)

## 허용 범위

- 예약·쿠폰 관련 backend 구현과 테스트
- 새 Flyway migration
- 승인대기 만료 Scheduler, Service와 수동 관리자 Job API
- OpenAPI와 생성 API Client
- `docs/tasks/active/M3-14.md`, `docs/tasks/completed/M3-14.md`

## 제외 범위

- 과거 confirmed 자동 종료
- 수업 종료 시각과 알림 시스템
- 회원·관리자 화면
- 관련 없는 리팩터링, 라이브러리 교체, 포맷 전체 변경

## 완료 조건

- [ ] `approval_expired`가 비점유 종료 상태로 저장·조회된다.
- [ ] Job이 만료 대상의 쿠폰 점유와 정원을 같은 트랜잭션에서 한 번만 반환한다.
- [ ] 입금대기는 2시간과 수업 시작 중 빠른 경계에 만료된다.
- [ ] 검증 명령이 모두 종료 코드 0으로 성공한다.

## 검증 명령

```bash
mise tasks --all
mise run verify:m3-14
mise run backend:convention
mise run verify:changed
```

## 중단 조건

- 기존 이력을 손상하는 migration이 필요하다.
- 쿠폰 점유 반환을 예약 상태 전이와 같은 트랜잭션에 둘 수 없다.
- 같은 원인의 검증 실패가 세 번 반복된다.
