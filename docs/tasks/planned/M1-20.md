# M1-20: 관리자 회원·특수 승인 화면

## 상태

`READY`

## 목표

관리자가 회원의 기승 정보와 특수 클래스 승인 상태를 조회하고 마장마술·장애물 승인을 변경하는 반응형 웹 화면을 제공한다.

## 담당

`frontend`

## 선행 작업

- M1-02A 완료
- M1-02B 완료

- [제품 요구사항](../../product/requirements.md)의 클래스와 관리자 기능
- [MVP 1 제품 범위](../../product/mvp-1.md)의 회원 등급 및 특수 클래스 승인 관리
- [API 초안](../../architecture/api.md)의 회원과 쿠폰 중 관리자 회원 API
- [도메인 모델](../../architecture/domain-model.md)의 `Member`
- [시스템 개요](../../architecture/system-overview.md)의 웹과 `members` 경계
- `.agents/rules/frontend.md`의 React와 FSD-lite 컨벤션

## 제외 범위

- 쿠폰 등록·보정과 예약 운영 화면
- 일반·특수 기승 횟수 수동 보정
- 회원 가입·로그인과 JWT 저장 정책
- 생성형 API 클라이언트 직접 수정, 백엔드 정책 재구현, 관련 없는 전역 스타일 변경

## 완료 조건

- [ ] 관리자 회원 목록과 상세에 이름, 일반·특수 기승 횟수, 특수 클래스 승인 상태, 파생 대마장 이용 가능 여부가 표시된다.
- [ ] 마장마술·장애물 승인 변경은 관리자 회원 API를 호출하고 성공 응답의 최신 상태를 화면에 반영한다.
- [ ] 로딩·빈 목록·조회 실패·권한 거부 상태와 승인 변경 중 중복 제출 방지가 키보드로도 동작한다.
- [ ] 320px 이상 반응형 컴포넌트 테스트와 검증 명령이 모두 종료 코드 0으로 성공한다.

## 검증 명령

```bash
mise tasks --all
mise run verify:m1-20
mise run verify:changed
```

## 검증 증거

| 명령 | 종료 코드 | 핵심 결과 |
|---|---:|---|
| `mise tasks --all` | - | READY 단계, 구현 후 `verify:m1-20` 등록을 기록한다. |
| `mise run verify:m1-20` | - | READY 단계, 회원 조회·특수 승인 컴포넌트 테스트 결과를 기록한다. |
| `mise run verify:changed` | - | READY 단계, 변경 영역 품질 게이트 결과를 기록한다. |

## 중단 조건

- M1-02A가 관리자 회원 목록·상세 조회 계약이나 기승 횟수·승인·파생 대마장 이용 필드를 제공하지 않는다.
- M1-02B가 마장마술·장애물 승인을 독립적으로 변경하고 최신 회원을 반환하는 계약을 제공하지 않는다.
- 권한 거부 응답을 회원 없음 또는 일반 조회 실패와 구분할 수 없다.
- 요구사항 충족에 `frontend/packages/api-client/src/**` 직접 수정이나 허용 범위 밖 인증·공통 UI 변경이 필요하다.
