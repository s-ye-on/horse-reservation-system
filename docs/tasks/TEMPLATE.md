## 중단 조건

다음 중 하나라도 해당하면 구현을 멈추고 상태를 `BLOCKED`로 변경한다.

- 입력 문서끼리 정책이 충돌한다.
- 요구사항을 만족하려면 허용 범위 밖 파일 수정이 필요하다.
- 선행 작업이나 필요한 API·스키마가 존재하지 않는다.
- 데이터 삭제, 비가역 마이그레이션 또는 기존 이력 손상 가능성이 있다.
- 인증·권한 또는 개인정보 처리 기준이 명확하지 않다.
- 필수 검증 명령이 없거나 반복 실행 시 결과가 불안정하다.
- 완료 조건을 자동 검증할 방법을 정의할 수 없다.
- 예상 작업이 주요 동작 1개 또는 완료 조건 4개를 넘어간다.
