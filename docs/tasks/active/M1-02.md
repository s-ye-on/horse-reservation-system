- [ ] JWT `sub`로 현재 회원을 식별한다.
- [ ] DB의 일반 기승 횟수로 현재 등급과 낮은 일반 클래스를 응답한다.
- [ ] DB의 마장마술·장애물 승인 상태를 예약 가능 클래스에 반영한다.
- [ ] 권한·응답 테스트와 검증 명령이 모두 성공한다.

## 중단 조건

- JWT `sub`와 `Member.authSubject`의 식별 계약이 충돌한다.
- 예약 가능 클래스를 계산하려면 회원 상태를 JWT claim에 저장해야 한다.
- 허용 범위 밖의 스키마 또는 인증 설정 변경이 필요하다.
- 본인 조회 권한과 존재하지 않는 회원 응답을 자동 검증할 수 없다.
