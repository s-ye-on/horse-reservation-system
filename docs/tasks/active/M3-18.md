# M3-18: 시간 기반 예약 생명주기 전체 회귀

## 상태

`READY`

## 목표

시간 경계 상태 전이, API 읽기 모델과 회원·관리자 화면을 전체 품질 게이트와 브라우저
흐름으로 고정한다.

## 담당

`qa`, `backend`, `frontend`, `docs`

## 선행 작업

- M3-16, M3-17 완료

## 입력 문서

- [운영 정책](../../product/policies.md)
- [ADR-013](../../architecture/adr-013-time-based-reservation-lifecycle.md)
- M3-13 ~ M3-17 완료 Task

## 허용 범위

- 시간 기반 예약 정책 관련 backend·frontend 회귀 테스트
- `frontend/apps/web/tests/e2e/**`
- 실제 회귀 결함에 한한 M3-13 ~ M3-17 구현 수정
- `docs/tasks/active/M3-18.md`, `docs/tasks/completed/M3-18.md`

## 제외 범위

- 수업 종료 시각과 grace period
- 외부 알림·APM·부하 시험
- 모바일 네이티브 E2E
- 관련 없는 리팩터링, 라이브러리 교체, 포맷 전체 변경

## 완료 조건

- [ ] 정확한 수업 시작 전후 Command 경계와 만료 Job이 회귀 검증된다.
- [ ] 회원 예정·지난 예약과 관리자 출석 화면의 핵심 브라우저 흐름이 통과한다.
- [ ] 전체 backend, OpenAPI, web 품질 게이트가 통과한다.
- [ ] 검증 명령이 모두 종료 코드 0으로 성공한다.

## 검증 명령

```bash
mise tasks --all
mise run verify:m3-18
mise run backend:convention
mise run verify:changed
```

## 중단 조건

- 경계 E2E를 운영 데이터나 보안 우회 없이 구성할 수 없다.
- 기존 정책을 완화해야 전체 회귀가 통과한다.
- 같은 원인의 검증 실패가 세 번 반복된다.
