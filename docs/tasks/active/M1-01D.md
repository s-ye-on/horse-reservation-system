## 완료 조건

- [ ] `Member.canUseLargeArena()`가 일반 기승 21회 이상 또는 마장마술·장애물 승인일 때만 `true`다.
- [ ] Entity가 `large_arena_allowed` 값을 제품 진실로 매핑하거나 노출하지 않는다.
- [ ] 기존 컬럼이 남은 MySQL 스키마에서도 회원 조회 통합 테스트가 성공한다.
- [ ] 검증 명령이 모두 종료 코드 0으로 성공한다.

## 중단 조건

- 저장된 `large_arena_allowed` 값이 과거 관리자 예외 정책으로 사용된 근거가 발견된다.
- 파생 계산에 회원 외 다른 aggregate나 운영 설정이 필요하다.
- 기존 컬럼을 즉시 삭제하지 않으면 Hibernate 검증을 통과할 수 없다.
- 완료 조건을 만족하려면 기존 migration 또는 컨벤션 변경이 필요하다.
