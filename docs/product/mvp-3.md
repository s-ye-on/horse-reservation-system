# MVP 3: 운영 효율화

## 목표

반복적인 관리자 업무를 줄이고 예약·쿠폰 처리 상태를 빠르게 파악할 수 있게 한다.

## 포함 범위

- 날짜·시간별 일괄 수업 완료
- 승인대기·입금대기·만료 대시보드
- 오래된 승인대기 단계별 경고
- 쿠폰 만료 자동 처리
- 회원·예약·쿠폰 통합 검색과 필터
- 관리자 감사 로그
- 운영 작업 실패 모니터링
- 예약 및 쿠폰 사용 내역 다운로드

관리자 예약 집계는 `Reservation`을 기준으로 날짜 범위의 전체 수, 상태별 수, 일자별
상태 수를 제공한다. 날짜를 생략하면 `Asia/Seoul` 기준 오늘 하루를 조회하며, 상태별
집계는 0건인 상태도 포함한다.

## 후속 검토

- 온라인 결제
- 메시지 알림
- 대기 예약
- 강사·말·마장 자동 배정
- 통계와 매출 분석
- 구보초보·구보 클래스 추가
- 기승 횟수와 회원별 예약 가능 클래스 승인의 분리

위 클래스·승인 모델 변경은 MVP-3 범위에 포함하지 않으며 ADR-009에 따라 MVP-3 완료
후 독립 Task에서 설계한다.
