# MVP 4: 회원 모바일 앱

## 목표

안정화된 Spring API를 사용해 회원이 Android와 iOS에서 예약과 쿠폰을 관리할 수 있게 한다.

## 포함 범위

- React Native, TypeScript, Expo 기반 회원 앱
- JWT 로그인 상태 유지
- 예약 가능 클래스 및 시간대 조회
- 예약 신청, 변경, 취소
- 내 예약과 상태 확인
- 쿠폰 잔여 횟수와 사용 이력 확인

## 제외 범위

- 모바일 관리자 기능
- 웹과 모바일 UI 컴포넌트의 강제 공유
- 오프라인 예약 확정
- 푸시 알림과 앱스토어 자동 배포 고도화

## 완료 조건

- Android와 iOS 개발 빌드에서 핵심 회원 흐름이 동작한다.
- 웹과 동일한 OpenAPI 생성 클라이언트를 사용한다.
- 예약 상태와 쿠폰 결과가 웹과 동일하게 표시된다.

## 선행 Gate

- MVP-3.1 완료 후 앱 골격과 인증 준비를 진행할 수 있다.
- 예약 달력, 신청, 내 예약, 쿠폰과 변경·취소는 MVP-3.2 전체 Gate와 OpenAPI diff 승인 후 시작한다.
