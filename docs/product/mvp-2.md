# MVP 2: 변경·취소 정책 자동화

## 목표

회원과 관리자가 예약 변경·취소를 처리하고, 마감 시각과 쿠폰 정책을 시스템이 일관되게 적용하게 한다.

## 포함 범위

- 회원 및 관리자 예약 변경
- 회원 및 관리자 예약 취소
- 전날 21시 전후 자동 판정
- 쿠폰당 무료 변경권 1회
- 평일 당일 내 시간 변경
- 주말 당일 변경 차단
- 관리자 차감·반환·처리 없음 선택
- 관리자 사유 메모
- 변경·취소·쿠폰 처리 감사 이력

## 완료 조건

- 변경 대상 정원을 원자적으로 확보한 뒤 기존 정원을 해제한다.
- 동일 요청 재시도로 무료 변경권이나 쿠폰이 중복 처리되지 않는다.
- 모든 예외 처리에 담당 관리자와 사유가 남는다.
- 회원에게 변경 전 예상 쿠폰 처리를 보여준다.
