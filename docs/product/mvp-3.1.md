# MVP 3.1: 운영 안정화

## 목표

MVP-1~3의 예약·쿠폰 API가 시간 경계, 동시 요청, 재전송, 보안 오류와 대량 목록에서도
일관되게 동작하도록 안정화한다.

## 포함 범위

- 당일 신규 예약과 수업 시작 시각 경계
- 관리자 수동 예약
- 과거 TimeSlot 관리 차단
- 동일 회원·동일 고정 시간대 활성 예약 중복 방지
- 생성 API 멱등성
- Command 잠금 순서와 제한적 deadlock 재시도
- ErrorResponse, Page, RFC3339 시간 계약
- 관리자 목록과 CSV 웹 UX
- 운영 JWT와 OpenAPI·E2E 하네스

## 제외 범위

- 가족 쿠폰 공유와 관리자 클래스 재정의
- 반복 수업 템플릿과 주간 일정 화면
- Google Sheets 연동
- 모바일 예약·쿠폰 화면

## 진행 Gate

작업은 `M31-00~05`, `M31-06~12`, `M31-13~17` 세 Checkpoint로 진행한다. 각 구간이
끝나면 검증 결과, 남은 위험, 다음 구간 진행 가능 여부를 보고한 뒤 다음 작업을 시작한다.

상세 품질 Gate는 [MVP-3.1 안정화 계획](../architecture/mvp-3-1-stabilization-plan.md)을 따른다.
